# 选择一条可以连续完成的学习路线

三条路线复用同一套教材，区别是先修门槛、证明深度和阶段作业。第一次学习建议选 A；已有数学专业训练可选 B，目标是实现算法与模型可选 C。课程并非每一高级定理都自包含，外引与待审事项在正文旁标记。

| 路线 | 起点与目标 | 学习安排 |
| --- | --- | --- |
| [A · 零基础入门](beginner.md) | 从集合、证明和度量走到开集、连续、紧致及连通 | 8课；约29小时；阶段证明项目 |
| [B · 数学专业进阶](advanced.md) | 基本群、覆盖、整数同调、上同调到流形 | 路线A及线性代数之后；逐课时间见课表 |
| [C · 计算与 AI 应用](computational.md) | 链复形、持续同调、损失与实际网络优化 | Python和矩阵基础；固定协议的合成项目 |

每条路线提供先修诊断、完整课表、当前路线的上一课/下一课、自评完成记录与阶段作业。记录仅在本机浏览器保存，不上传、不构成测评成绩；存储不可用时仍可阅读静态课表。选择路线后课程侧栏默认呈现这条路线，随时可显示完整导航。

完成记录按章节共享：清除一路线会清除其中章节在其他路线显示的完成状态。多个标签页不实时同步，请在一个标签页记录；需要看到其他页的新记录时刷新。

研究阶段可以在B/C基础上进入[完整课程目录](../curriculum.md)中的现代同伦、几何、医学或高阶网络专题；请先读相应的证明范围与先修条件。没有把“已有页面”当成所有方向已经完整讲授。
