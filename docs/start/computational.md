## 先修知识诊断

下面题目用于选择回读位置，不阻止进入课程。未掌握时先阅读反馈所列章节。

<div data-route-assessment>启用 JavaScript 可即时检查；下方保留题目与解释。</div>

1. ∂²=0 在同调定义中保证什么？

??? tip "第 1 题核对"
    边界属于循环，可取 ker∂/im∂。它使商空间合法，并不保证同调为零。回看同调初步。

2. 长度10⁻¹²的正持续条应怎样处理？

??? tip "第 2 题核对"
    核心保留，显示可另作提示。正短条可能改变Betti数，保留P0回归；显示容差不能修改计算对象。

3. 比较加入拓扑特征的模型，标准化和调参应使用哪里？

??? tip "第 3 题核对"
    训练集拟合、验证集调参，测试集留到最后。A2解释训练/验证/测试隔离；阶段项目公开固定协议与全部结果。

## 阶段项目：拓扑目标进入真实反向传播 {#project}

完成[轻量神经网络优化项目 C](../ai/projects/topology-optimization.md)：生成固定划分的小路径分割数据，训练普通损失与加拓扑项的同架构网络，运行评测并比较每个种子的结果。这里“真实运行”指实际优化网络参数，数据仍为合成；并非医学临床复现。

提交环境、命令、种子、原始预测和至少一个失败案例。解释寿命代理变小是否使固定阈值 Betti 数正确、错误的单分支先验会怎样损伤本来有两个分支的目标，以及配对切换时为何不能把软件分支值称作唯一经典梯度。

??? success "核对与论证要求"
    指标按测试划分一次汇总，不能为了让拓扑方案获胜反复选择测试结果。有限条寿命平方和不直接固定条的阈值位置；阈值Betti必须另算。把两个真实分支强制连成一个可能降低代理目标却增加分割错误。ties采用确定性规则只定义实现所选分支，需要与经典可微性分开报告。具体运行值以项目保存的JSON为准，不写预设收益。

验收：能够从零重跑，输出文件含协议与环境，检查梯度只在严格分支内进行，并明确一处不可微边界。完成后可转 A5/A6/A7 或整数同调 CT1 支线；这些不是本路线的隐藏必修项。
