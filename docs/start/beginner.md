## 先修知识诊断

下面题目用于选择回读位置，不阻止进入课程。未掌握时先阅读反馈所列章节。

<div data-route-assessment>启用 JavaScript 可即时检查；下方保留题目与解释。</div>

1. f⁻¹(U) 是什么？

??? tip "第 1 题核对"
    使 f(x) 属于 U 的所有定义域点。逆像由属于关系定义，不要求可逆。回看 PRE1 的逆像例题。

2. 要否定“所有 x 都满足 P(x)”，需要什么？

??? tip "第 2 题核对"
    至少有一个 x 不满足。全称命题被一个反例推翻；PRE2训练量词否定。

3. 若 d(x,y)<r，r−d(x,y) 有什么作用？

??? tip "第 3 题核对"
    给出 y 周围仍留在开球内的正半径。用三角不等式证明 B(y,r−d(x,y)) 包含于 B(x,r)；PRE3和导论有全证。

## 阶段项目：同一集合的两个拓扑 {#project}

取集合 $X=\mathbb R$，一份使用通常拓扑 $\tau_u$，另一份使用离散拓扑 $\tau_d$；再考察子集 $Y=[0,1)$。

提交一份2–4页证明稿：①验证 $\tau_u\subsetneq\tau_d$；②分别判断两个方向的恒等双射是否连续；③给出在 $Y$ 中相对开但在 $X$ 中不开放的集合；④说明有限个检验点为什么不能证明连续；⑤选择本路线两道证明题独立完成，并标出所用定义。

??? success "核对与论证"
    通常开集都是子集，故包含成立；单点集在离散拓扑开、在通常拓扑不开，故为真包含。恒等映射 $(X,\tau_d)\to(X,\tau_u)$ 的每个开集逆像离散开，所以连续；反向单点逆像不通常开，所以不连续，连续双射不自动同胚。$[0,1/2)=Y\cap(-1,1/2)$ 相对开，却没有包含0的通常开球落在其中。有限采样没有穷尽所有点及邻域，也不能控制采样间的不连续点。

验收：每个判断写逆像或开球论证，不能只给“是/否”；能解释一处反向蕴含失败。本项目没有自动评分器，勾选只记录自己的学习进度。建议请同学交换证明寻找遗漏假设。
