# 微分拓扑

微分拓扑（differential topology）研究光滑结构、映射与变形。按研究生课程要求，需要多元分析、逆函数定理、常微分方程及点集拓扑；D2 之后还使用同调、定向与对偶。

路线为 D1 → D2 → D3，随后学习 D4 的 Morse 理论与 D5 的向量丛。章节提供常秩、正则原像、参数横截、同伦算子、Stokes、无临界值形变和 Morse 不等式的证明。Sard、Whitney、完整 de Rham 比较、Morse 柄附加及特征类一般构造明确作为引用或进一步专题，不声称已从零证明。
