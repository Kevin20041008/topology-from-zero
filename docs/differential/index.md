# 微分拓扑

微分拓扑（differential topology）研究光滑结构、映射与变形。本卷按研究生层次展开，外部先修为多元分析、逆函数定理与线性代数；流与Morse理论另需常微分方程。映射度与全局de Rham比较使用整数同调和定向，不能仅靠一幅曲面图替代先修。

**未发布候选。** D1–D5已有正文，本批完成D1–D2的十二节教学结构、各8题完整答案及原创图解；这不表示整个微分拓扑课程完成。D3可在D1后并行阅读，D4另需D2与胞腔同调，D5依赖形式和上同调。
