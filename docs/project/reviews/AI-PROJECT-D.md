## 实际软件检查

11项测试通过：

1. 512个3×3二值掩膜，对照显式F2格边/格面边界矩阵，检查边界复合为零、Betti和Euler。
2. 729个2×3灰度输入，对照独立图边界约化；每例5阈值共3645次β0核对。
3. 2×2独立Bernoulli的16种结果逐项加权，对照期望多项式。
4. 31个像素导数与19参数小网络全梯度中央差分；误差阈值仅用于浮点求导测试。
5. 真正正短条、最小正subnormal、空/非法输入、指标空掩膜、依赖返回空骨架、24图哈希和组间互斥。
6. 固定LF的源文件与数据清单字节哈希，防止Git换行规范化使其他平台检出后证据失效。

完整训练6组，每组100轮；本地Windows CPython3.14.3、NumPy2.5.2、单线程BLAS环境；最终权重、每轮轨迹、各集合全部概率和逐图指标公开。跨平台精确重现不作保证，CI在自己的环境另存完整训练并重算。

最终同环境完整重跑通过：六组最终参数、100轮轨迹、监测记录及训练/验证/测试的全部概率逐项一致；没有降低断言。证据为 validation/v06/image-validation.json。另已程序化核对正文两行结果表的8组均值/标准差、summary与完整记录一致性、12节结构、两处梯度加号、候选分支链接及两幅SVG的XML，结果见 validation/v06/image-content-checks.json。上述证据不替代数学同行评审。

## 开发中发现的问题及处理

- 初次精确重跑曾失败：验证脚本在设置线程变量前导入NumPy，导致大矩阵归约顺序与训练进程不同。已让验证与训练都先设置线程环境；没有放宽任何概率、拓扑或轨迹断言。
- 非空掩膜的骨架若为空，clDice分母原会为零。已显式抛错，并加入mock空骨架回归。
- 初稿易把“训练过程中Euler代理降低”理解为“比基线更低”。正文给出种子11最终代理实际更高的数值，明确没有收益保证。
- 集成模型独立复核发现总logit梯度展示式漏了两个加号，已修正为BCE导数加上softDice与Euler导数之和乘sigmoid导数；训练代码中的加法本来正确，已有参数梯度测试与训练结果不受本次正文修订影响。
