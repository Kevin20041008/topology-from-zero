## 定义、命题与证明义务

| 编号 | 本章范围与已检查事项 |
|---|---|
| PRE5.1–5 | 群允许非交换；子模必须是加法子群；自由阿贝尔群与自由群不同；整数标量不允许任意除法 |
| PRE5.6 | 零子群单独处理；最小正元素与带余除法证明整数子群分类 |
| PRE5.7–8 | 陪集代表元独立的双向条件；正规核、第一同构定理的单射与满射 |
| PRE5.9–11 | 整数模结构唯一；有限秩子群自由的投影归纳；不声称任意子群基能扩充 |
| PRE5.12–14 | 张量积由自由阿贝尔群与关系构造；泛性质；商公式只除去像；张量破坏单射的非零源反例 |
| 自由秩说明 | 明确为有理张量后的维数；有限挠群秩零不等于群零 |

本章不冒领有限生成阿贝尔群分类唯一性的全证。整数矩阵的构造分解在 CT1 展开；一般同调系数变换与 Tor 函子属于后续理论。
