## 例题与八题解答

1. 形状5×7、7×2、7×7、7×4及通道权重4×6。
2. 平方范数非负，不能以符号抵消；核交双向。
3. 空心三角环B1秩2、调和核span(1,1,−1)；填面B2为该列后L1=3I。
4. 同调商良定义及投影残差仍为循环分别使用链条件；唯一性用像与正交补交零。
5. 反转一条边时B1右乘D、B2左乘D，明确矩阵并核对边界复合。
6. ReLU数值反例与奇函数恒等；固定偏置也需协变。
7. 三次成对通话无法证明三方共同事件；团复形是声明的建模选择。
8. 平方能量不变但丢失位置与相关信息，不推出预测正确。
