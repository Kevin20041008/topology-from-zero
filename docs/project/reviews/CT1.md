## 数学范围与证据

| 项目 | 检查结论与适用范围 |
|---|---|
| CT1.1–3 | 有限自由整数链；保留零形状；明确 AB=0、系数环、Smith 正号及整除链 |
| CT1.4 | 欧几里得余数降低主元；不整除尾块时引入元素再严格降低；有限递归终止；同步记录 U,V |
| CT1.5 | 初等操作保持子式理想；正因子由相邻行列式因子恢复；仅先证明给定表示矩阵的唯一性 |
| CT1.6 | 左右整数基变换诱导余核同构；自由与挠子分量；没有把域上秩当作全部群信息 |
| CT1.7 | 整数核由 V 的末列组成；先算 V⁻¹B 后截行；验证 AK=0、KR=B |
| CT1.8 | 像是有限秩自由阿贝尔群；提升像基构造直和补；独立参考公式不复用被测核基 |
| CT1.9 | 有限链群秩的交替消去；Euler 核对无法检测所有挠子错误 |

Smith 终止证明不是多项式位复杂度证明。实现仅接受精确 Python 整数；有理数运算用于幺模逆且检查逆确实整值，不使用浮点容差。
