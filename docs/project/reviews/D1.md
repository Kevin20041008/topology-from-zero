## 历史缺口与本批处理

旧记录指出光滑单位分解的紧穷竭、层间加细、局部有限性压缩在一句话中。本批实际补出：

1. 可数预紧坐标球覆盖 $O_j$；用有限个球覆盖 $K_i\cup\overline O_{i+1}$，取所选球的闭包之并构造 $K_{i+1}$。
2. 紧环带 $A_i=K_i\setminus\operatorname{int}K_{i-1}$，以及包含它的开区域 $E_i=\operatorname{int}K_{i+1}\setminus K_{i-2}$。
3. 每层有限对嵌套坐标球，外球的闭包落在原覆盖成员与 $E_i$ 内。
4. 若 $p\in\operatorname{int}K_N$，则 $i\ge N+2$ 的所有外球避开该邻域，故整个球族局部有限。
5. 使用明确的 $e^{-1/s}$ 光滑延零构造隆起函数，再局部有限求和与归一化。

同时补出曲线等价、切空间线性结构、切映射良定义、链式法则、常秩 $r=0$ 情形、正则原像 $n=0$ 情形和无理环面浸入的无界回返序列。历史正确内容未被移除；“原有内容已读过”不代替本批扩写后的再次审查。
