历史 M1 规划基线：2026-10-12，当时已发布 main 为 v0.3（`e15c7ac`）；42 篇研究生候选正文位于 PR #3（`2ef2155`），尚未合并。本阶段依赖该候选版本，独立分支 `codex/m1-foundations-batch-1`。所有方向最终按研究生课程深度建设；预备知识和点集基础保持初学者可进入的连续证明链。

这是一份有验收义务的长期课程清单，不是完成声明。**现有内容保留原路径，扩充原章；未写单元只列在本计划，不创建空白正文。** 每行可拆成连续课次，但不以页面数量代替学习深度。

状态：`已有·待升级` 表示有正文及历史作者检查，但尚未满足新十二项模板/逐题答案/独立复核；`本批 Reviewed` 表示正文、题解已写并经独立模型复核；`待建设` 表示没有独立完整单元。正式章审查状态另按 [审查协议](MATH_REVIEW_PROTOCOL.md)记录；自动化验证不是证明认证。每个单元的证明目标，若暂不能全证，必须逐定理写明外部先修、精确陈述、证明概要及未履行义务，不能默认为已全证。

全书共同外部先修：实数完备性与初等代数；微分卷加多元分析、逆函数定理、ODE；同调卷先建设群/模/线性代数；统计与AI卷显式要求概率、优化与基本机器学习。各行“先修”是本站代码，完整有向图见 [知识依赖图](PREREQUISITE_GRAPH.md)。
