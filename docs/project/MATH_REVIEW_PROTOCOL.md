# 数学审查协议

## 状态与证据的含义

每个正式章在 `project/reviews/` 有独立记录，含版本、审查方式、定义/命题/证明/题解清单、计算证据和未尽义务。状态是单章范围，不能由网站构建整体授予。

- **Draft**：正文存在，或正按新模板补写。历史作者检查不能自动升级新标准。
- **Reviewed**：有人或明确标识的独立模型逐条复核定义、主要论证与题解；写出身份/方式和范围。模型复核不称人类同行评审。
- **Verified**：在Reviewed基础上，章内关键有限计算及适用自动化测试通过。仅标明具体输入、系数、算法、命令/结果；不代表所有定理已形式化验证。
- **Advanced Outline**：精确陈述和概要已写，指定重大证明未在本教材展开；必须列外部先修、引用定位、关键引理、未完成证明义务。可局部验证计算，但不据此升级整章证明状态。

内容状态与测试状态分别记录。空计划条目只写“待建设”，不冒充Draft正文；旧章规范化待完成不等于删除其正确内容。

## 逐章检查表

1. 定义：对象、域/陪域、拓扑、系数环、基点、定向、有限性、空集边界；术语首次中英并列。
2. 命题：量词、必要/充分方向；紧致/局部紧致、T1/Hausdorff、连通/道路连通、维数、边界假设；尝试去掉一个假设并构造反例。
3. 证明：逐步依赖定位；不循环；代表元无关；符号/索引/定义域匹配；非平凡“显然”需展开；外引精确标注。
4. 计算：整数/有限域区分；矩阵形状、边界平方零、Euler与Betti；浮点端点与图形阈值分开；退化输入。
5. 例题/习题：四类例子、6–12题，基础/证明/反例/综合/挑战；每题有论证式答案，分步提示不能代替完整答案。
6. 教学：先修已提供或明确外部工具；定理编号为“章代码.序号”（如PRE1.4），不随网站导航顺序变化。
7. 引文与版权：真实书名/版次/已核章节/来源；记录访问范围，不虚构页码、DOI或逐页核查。解释、题目、图形均原创。
8. 工程：本章题库键、章节清单、搜索、MathJax、前后导航、旧URL/锚点；源码块公式独占行且前后留空行。

## 新章统一模板

按顺序写十二项：学习目标；先修知识；问题引入（直观解释）；严格数学定义；定理、引理、推论与证明；典型例题（正例与反例）；几何直观与原创图解；编程实验（不适合时说明理由）；课后习题；习题解答；本章总结；参考文献。解答允许链接独立页，必须与题号一一对应。

主要定理要么有完整证明，要么紧邻标记“完整证明未在本教材展开”，列原因、假设、关键引理和真实参考定位。研究级大定理不靠堆长证明充数。一般结论不能由有限实验推出。

## 数值与实验审查门槛

- P0 A：两点距离 `1e-10`，epsilon=0，beta0=2；P0 B：薄矩形在 `0.5000000000125` 时Betti=(1,1)。保留严格断言和旧失败证据。
- 核心只删真正零长度条；不按显示容差丢同调类。Rips使用binary64边长的半径滤过，极近点不可固定小数舍入；溢出/半尺度下溢应拒绝并解释。
- 曲面数学商空间、渲染索引和抽象单纯复形分开；Mobius识别 `(n,j)~(0,m-j)`。Euler与d²只能证明内部一致性的一部分。
- GUDHI对照只支持指定输入、相同边出生值和系数下的一致性；不能变成任意点云正确性的证明。
- AI必须分开理论保证、经验结果、算法假设和研究猜想；无运行证据不得写指标提升。

## 审查与合并流程

作者自检 → 独立模型或人类复核（清楚区分）→ 修正及复测 → PR自动检查 → 维护者数学审阅 → 获授权后合并/发布。不能因自动化通过跳过数学审阅；本批不自动合并依赖PR或发布候选。

严重错误记录反例和影响范围，阻塞受影响章节发布；非阻塞的高级证明义务公开列出。M7需人类领域审阅者检查重大定理，当前没有人类签署，不声称形式化验证。
