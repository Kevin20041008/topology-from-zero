## 具体发现与整改状态

1. **已修正，数学论证错误：距离集合不一定有上界。** `docs/exercises/pre3-solutions.md:29` 初稿称选一个 `a0∈A` 就得到距离集合的有限上界 `d(x,a0)`。反例：通常实线取 `x=0,A=R`，距离集合无界。当前改为集合非空且有下界，因此存在实下确界，并有 `0≤inf≤d(x,a0)<∞`，这才是正确论证。随后取下确界证明 1-Lipschitz 的步骤成立。

2. **已修正，实现与正文不一致：严格半径开球计算原先缺失。** `docs/preliminaries/metric-spaces.md:195` 承诺实验计算开球，但初版仅做矩阵公理检查。当前 `docs/javascripts/foundations-core.mjs:68` 新增 `integerOpenBall`，先检查伪度量公理，再要求集合内球心、合法正整数半径，以严格 `<` 筛点。`docs/labs/foundations.md:34` 起有球心与半径控件，`scripts/test_foundations.mjs:102` 起保留精确边界排除与零距离类回归。代码不会用容差纳入等距离边界。矩阵点编号与 PRE3 的 a,b,c 建议显式写成 0↔a、1↔b、2↔c，以减少教学操作歧义。

3. **需要修正，缺少假设：D4.1 未声明 a≤b。** `docs/differential/morse-handles.md:15`：命题只说 `f⁻¹([a,b])` 紧且无临界点，则 `M^a` 是 `M^b` 的强形变收缩。取 `M=R,f(x)=x,a=1,b=0`，闭区间为空，条件成立，但 `M^1` 甚至不是 `M^0` 的子集。建议声明 `M` 为无边界光滑流形、`f:M→R` 光滑、`a≤b`；等号时恒等映射即可，严格不等时按原梯度流证明。该问题是旧内容顺读发现，不是 PRE3 新章引入。

4. **需要统一标识，证明范围：H3/Q2 原“证明…□”与新增警告不一致。** `docs/algebraic/homology/cellular-coefficients.md:19,40` 和 `docs/algebraic/cohomology/duality.md:37` 仍以完整证明的外观叙述，警告在后面。数学边界警告本身准确：非正则 CW 对的相对同调引理、UCT 自然右端映射、对偶胞腔关联数符号与帽积比较尚未展开。建议在论证前声明“条件推导”或“证明思路（完整证明未展开）”，将条件证明的终止与整条定理的证明终止分开。不要为达到 Reviewed 标识而删去这些义务。

5. **轻微记号一致性：正整数序列应取正整数截断指标。** `docs/preliminaries/metric-spaces.md:40–51` 定义序列从 1 开始，但写 `N∈N`；PRE2 明确 `N` 含 0，而 `docs/exercises/pre3-solutions.md:17` 用 `x_N` 固定项。常用惯例可解释只对有效序列指标量化，但初学教材宜直接写 `N≥1`，避免出现未定义的 `x_0`。不改变结论或证明核心。
