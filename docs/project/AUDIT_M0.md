- 02：F2 消元而非实数无符号秩；含 D1·D2=0、空矩阵、空心/实心三角形、方形尺度和伸缩测试。仅教学固定小数据，不是健壮的通用数值 API；例如 NaN、溢出和極端尺度没有像 JS 核心一样全面拒绝，后续扩展输入时应补契约及退化测试。参数是边长阈值 r，与浏览器 ε 的关系 r=2ε 已写明。
- 03：整数有符号边界先检查 D1·D2=0，再模 2 算核、像、杯积配对；环面与 S1∨S1∨S2 的同 Betti/异杯积反例正确。RP2 的乘 2 例子是指定胞腔矩阵演示，不是通用 Smith Normal Form 实现。
- 04：96 独立合成点云、固定种子、64/32 分层划分、三种特征共享最近质心分类器，标准化只拟合训练集。全部有限正 H1 条参与特征；没有测试精度门槛、调参或伪称一般优势。当前只是单种子合成演示；没有真实数据、置信区间、稳健跨种子证据，不能升级为方法性能主张。

## CI 与检查局限

- `.github/workflows/pages.yml` 对 PR 执行 Node、GUDHI、Notebook、严格 MkDocs 构建和静态链接/数学标记验证。部署任务仅在非 PR 且 main 上执行；不会从 PR 分支直接发布。

- 明确缺口：静态链接检查跳过所有 `/` 开头的地址（原因为 404 页），因此不能把它描述为验证了所有站点绝对路径；动态 MathJax 渲染、WebGL、实际交互反馈需浏览器验收，不属于现有 CI 的自动化 DOM 运行验证。
- `test_curriculum.mjs` 硬约束当前 42 章/8 方向。增加新章应有据更新课程清单与规模约束、保留原章和原题契约，不能只删断言。
