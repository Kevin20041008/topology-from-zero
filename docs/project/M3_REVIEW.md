## 3. D1 逐命题复核

| 对象 | 核对结果与具体理由 |
| --- | --- |
| 流形与光滑图册 | 默认 Hausdorff、第二可数、有限维、无边界；图册检查包含全部有序图对，因此转移和逆转移都光滑。光滑映射先保证连续，再讨论局部表达 |
| D1.A 曲线切空间 | 换图用固定点的可逆 Jacobian，等价关系不依赖图；直线在坐标中的逆像实现任意速度；坐标搬回的线性结构因线性转移一致 |
| D1.B 切映射 | 等价曲线经光滑映射仍等价；坐标导数给线性性；复合的作用点明确为 f(p)，没有把不同点的切空间混用 |
| D1.1 常秩 | 正秩情形构造可逆源坐标，秩恒定迫使尾变量偏导在整个矩形为零，再用线段论证消去依赖；目标变换给出显式逆。r=0 单列局部常值，空变量块与零维情形相容 |
| D1.2 正则原像 | n>0 的满秩子式在邻域保持，切片图册继承正确拓扑；核等于包含映射下切空间。n=0 单列，空纤维不误解释成含有负维点 |
| D1.3 适当单射浸入 | 在目标紧邻域上利用适当性证明闭映射；单射闭映射到像的逆连续。紧源情形使用目标 Hausdorff，使紧集闭后拉回 |
| D1.C 光滑隆起 | 正侧导数是多项式乘指数，估计保证各阶导数趋零；分母两个自变量之和严格正，因此归一化无零分母；内球值1和外球值0逐项成立 |
| D1.4 紧穷竭 | 从可数预紧坐标覆盖逐步有限扩充，得到紧集嵌套于下一层内部并覆盖流形；初始负指标明确，空环带不选球 |
| D1.4 局部有限与归一化 | 外球位于相邻环带控制区；在某层紧集内部的邻域只可能遇到有限低层，每层球数有限。紧支集延零光滑，局部有限和处处至少1，除法不扩大支集 |
| 尖点与无理浸入反例 | 尖点是到像的拓扑同胚，但退化导数排除光滑嵌入；无理绕环面用鸽巢原理构造无界回返序列，确实否定到像反函数的连续性 |

预审特别检查了两个不能省略的步骤：常秩假设不是只在一个点的秩条件；单位分解的局部有限性不是“每点仅有限项非零”。最终稿分别给出了矩形内的导数论证与紧环带的邻域控制。

## 5. D2 逐命题复核

| 对象 | 核对结果与具体理由 |
| --- | --- |
| 横截定义与法商 | 切空间之和等于目标切空间，等价于导数到法商满射；未引入不必要的 Riemann 正交补。S 是嵌入子流形但不默认闭 |
| D2.1 横截原像 | 适配坐标的法向分量与法商线性同构；正则零集给嵌入原像及切空间核。余维超过源维数时只能空；余维0时是开子流形 |
| 闭性与紧性 | 局部横截不推出闭性；S 闭才由连续性得原像闭，M 再紧才得原像紧。开线段与紧圆周中的开弧均为有效反例 |
| Sard 外引版本 | 有限可微要求为正整数 r 大于 max(m−n,0)，零测指目标坐标；目标零维时直接证明临界集空，m<n 时是整个像零测而不是像空 |
| D2.2 参数横截 | W 的切空间是总法商映射的核。核上投影满射推出位置映射满射时确实用了总满射；反向显式抵消参数方向。空纤维与零维参数分别处理 |
| 好参数非开放例子 | 总参数导数为负1；零参数的根全部正则，而在逐渐增大的临界点处得到趋零的非零坏参数。没有与 Sard 的零测结论冲突 |
| D2.3 度定义与有限性 | 限非空、连通、闭、定向、同维且 n≥1；正则纤维为闭、紧、离散集合，从单点开覆盖得有限。未把 S 的一般非闭情形混进单点纤维 |
| D2.3 条件计数证明 | 绝对到相对同调交换图的空间对映射合法；有限局部分量的生成元相加给符号和。空纤维使左下群为零；同伦不变通过 H1，不假设任意同伦横截 |
| D2.4 满射与复合 | 像外点是空纤维正则值，非零度推出满射；复合公式由同调函子性得到，没有误写逆向 |
| 圆周、球面与系数 | 零幂单列像外正则值，负幂保留负符号；反足映射包含外法向的额外变号，得到 n+1 个负号。S⁰ 不属于连通正维公式；模2版本保留其余全局假设 |
| 非紧反例 | 根逃向无穷导致计数改变；更强例子中每个切片适当但整个同伦不适当，精确显示逐参数条件不足以替代统一紧致控制 |

基本类存在、局部定向兼容和局部微分同胚的同调符号比较在 D2.3 前明确外引。因此本次认可的是在这些工具成立前提下的条件推导，不把它扩张为一般流形定向定理已在本教材证明。

## 7. 两幅原创 SVG 的数学核对

**D1 局部标准形图。** 源中的第三方向线段经投影对应到二维点，再包含到目标零平面，符合 m=n=3、r=2。经修正后目标三轴共点，平面两轴方向与所画平面一致。图和文字均限定局部坐标，不用它推断全局纤维或全局嵌入性。

**D2 横截与符号图。** 左上两条直线在交点方向独立；左下二次曲线的顶点恰在水平线上且切线水平。右侧二次曲线的零线在顶点之上，交于左右两点；屏幕纵坐标向下这一显示约定与数学坐标的导数符号转换正确，左根标负、右根标正。SVG 中的交点位置和切线方向与二次曲线一致，未把相切画成横截。

这里检查的是可维护 SVG 的几何对象和数学标记。屏幕尺寸、主题、字体及 MathJax 的实际显示验收属于工程检查，不能由这项源码核对代替。
