# 小规模学习者试用：可执行方案

**状态：方案已准备，尚未招募、尚未进行试用、没有受试者数据。** 本文不报告教材提升了证明能力，也不把浏览器测试当成学习效果证据。网站不自动收集研究数据；以下记录须在真实参与者同意后由执行者手工填写。

## 1. 目的与可回答的问题

邀请 **5–10 名真实成年学习者**，观察路线 A 三级证明训练能否被理解和完成，找出具体的内容与界面障碍。此批只回答：学生是否能正确复述量词、识别错误步骤、独立完成指定迁移题，在哪一步需要帮助，以及反馈是否误导。

这是形成性试用，没有随机对照组，人数也不足以支撑普遍效果或因果结论。“排列通过”“觉得有用”“训练后写出证明”分别是操作、主观感受和特定任务表现，不能互相替代。研究生课程的整体系統效果不在本方案可推断范围内。

## 2. 执行前准备

- 冻结候选分支的 Git SHA，填写实际日期、网站构建 SHA、浏览器与设备。试用期间如修复代码，应标明哪些记录来自旧版本。
- 指定一名主持者和至少一名未参与该题编写的数学评价者。理想情况下由两名人类评价者独立读证明；若只有一人，如实记录，不能称双人盲评。
- 维护者自行邀请志愿者。本仓库没有联系任何人；不代填姓名、同意、得分、访谈或成功率。
- 给每位实际参与者分配匿名编号。不要在公开反馈表中记录姓名、邮箱、学校或可识别个人的手写签名。
- 在参与者设备上验证[训练页面](../exercises/proof-workshop.md)可打开；准备纸笔版本、纯键盘操作或关闭脚本的替代方式。
- 下载空模板：[观察记录 CSV](templates/learner-observation.csv)、[证明评价 CSV](templates/proof-rating.csv)、[学习者反馈 Markdown](templates/learner-feedback.md)。这些文件只有字段/问题，没有伪造示例行。

## 3. 参与说明与同意脚本

主持者在开始前朗读或展示：

> 我们希望找出教材和练习的困难，不是在给你定级。你可以跳题、停止或撤回尚未匿名汇总的记录，不需要解释。我们默认不录音、不录屏，也不收集姓名。你可以用纸笔，不必在网站保存输入。经你同意，我们会记录任务时间、使用的帮助、匿名证明文本与反馈，用于修改教材。任何公开原句或完整证明需要你另外同意；不同意公开不影响参与。你愿意继续吗？

只记录实际回答 `yes/no`。没有同意就结束，不填写任务结果。若希望录音、录屏、公开原文或延迟回访，须单独说明并取得同意；本方案的默认流程不需要这些操作。原始记录由指定维护者本地保存，在执行前明确保存期限和撤回方式；建议完成修改与核对后30天内删除原始可识别材料，只保留同意公开的匿名统计与问题摘要。

网站的本机保存按钮是学习工具，不是研究同意，也不会把草稿自动交给研究者。共享设备上建议不保存，或在结束时由参与者主动删除本题记录。

## 4. 学习者准备与任务分配

开始前询问其集合、量词、度量、开集与连续性学习经历，允许回答“不确定”。让其用两分钟解释“逆像”和“对每个 x，存在 r>0”的先后关系；这些只用于选择合适章节，不计成效果前测。

每人选择两章，预计60–75分钟。若已熟悉该题或看过答案，必须记录 `prior_exposure=yes`，该题不能作为新的独立迁移证据。两章都须满足正文先修；不能让零基础参与者未经学习直接证明闭集粘合。

| 可选任务组 | 必要准备 | 重点观察 |
|---|---|---|
| PRE1 + PRE2 | 集合、函数、整数奇偶 | 量词、逆像、双向证明与逆否 |
| PRE3 + spaces | 已学度量及拓扑定义 | 逐点半径与统一半径、空族环境 |
| bases + PS1 | 已学开集、基、子空间与闭包 | 局部细化与相对/环境结构 |
| continuity + connectedness | 已学前述基础及连续性 | 有限性、分离与非空条件 |

前四组可以覆盖八章；第五至第十位用于重查已发现的困难或尚未覆盖的学习背景，不规定虚假的平均分组结果。如果没有足够准备合适的参与者，公开“该章未试用”，不要用其他章的数据填补。任务顺序可轮换，但这不构成随机对照实验。

## 5. 单次流程与主持者规则

| 阶段 | 建议时间 | 操作与应记录内容 |
|---|---:|---|
| 同意、设备与先修确认 | 8分钟 | 实际同意、版本、先修经历；不收集真实姓名 |
| 第一章层1 | 4分钟 | 在展开说明前口述/写出目标、量词、假设；记原话或经同意的简短摘录 |
| 第一章层2 | 5分钟 | 排列与排错；记首个错误类别、尝试次数和是否理解反馈 |
| 第一章层3 | 10分钟 | 参考答案保持折叠，独立写迁移证明；记录所有提示/答案使用 |
| 第二章同样三层 | 19分钟 | 同样规则，避免主持者提前指出本章关键结论 |
| 无脚本或纯键盘检查 | 4分钟 | 找到同一任务、展开提示/答案、继续静态阅读 |
| 回顾访谈 | 8分钟 | 区分“操作方便”和“证明理解”，收集具体误解 |
| 整理与退出 | 3分钟 | 参与者核对可公开范围；可选删除本机草稿 |

允许延长或提前结束，记录实际时间而非强制使所有人完成。超过预定时间仍未完成时标记 `incomplete`，不能填为失败或零分来代替未知。

主持者先等参与者描述困难，不主动补证明。帮助分级：`none`（无帮助）、`ui`（仅解释按钮）、`hint1`、`hint2`、`solution`（已看完整答案）、`human_math`（主持者提供数学线索）。记录第一次使用的时间与最高帮助等级。看过完整答案后完成的文字标记为借助答案，不能并入“独立完成”数量。

层2通过后可问：“如果把你的顺序反过来，哪一步缺了条件？”不能问诱导式的“你现在是不是已经掌握了？”层3没有自动评分；允许用与参考解不同的正确论证。

## 6. 人工评价与可选延迟迁移

使用每题已有的四项量规。每项由人类评价者记 `0`（缺失/错误）、`1`（方向正确但有需补的实质步骤）、`2`（论证完整）。另记录 `critical_gap`，例如缺失满射、偷换环境空间、由数值例子推出一般命题。总分只能描述这道题，不给全课程认证。

评价者先只看到题面、匿名证明和实际使用的帮助，尽可能不看主观满意度。两人分别打分后记录分歧与解决依据；不能自动平均后抹掉数学争议。若证明使用未核查的新方法，标记 `needs_review`，不因与范文不同判错。

可选3–7天后进行一次10分钟新迁移任务，须先取得回访同意。建议给已完成 PS1 的参与者：

> A 在 X 中稠密，U,V 在 X 中开，且 A∩U⊆A∩V。证明 U⊆cl_X(V)。若 U 不开，结论是否仍成立？

这道题不放入训练题库。评价者答案见[人类审阅材料](HUMAN_REVIEW_PACKET.md#delayed-task)。若参与者已经看过该页答案，应改报“已暴露”，不能假装是未见迁移。没有实际延迟回访就保留“未执行”；不补造保持率。

## 7. 数据表字段与汇总原则

观察表每行对应一个真实任务阶段，使用秒数和实际状态；未知留空，不用0代替缺失。证明表记录评价者匿名编号、四项评分、关键缺口、不同论证、帮助等级及处理结果。学习者反馈允许“没有帮助”或负面意见。

最终报告至少给：实际邀请/同意/完成数量、版本、先修分布、各章实际人数、独立/借助帮助/未完成数量、典型错误、评价者分歧、具体改动及未解决问题。小样本可给逐人匿名结果，不用没有依据的显著性、因果提升或泛化百分比。

报告必须把以下证据分开：代码能运行；步骤依赖检查正确；学生操作成功；学生在未看答案时给出可信证明。未招募、未进行的当前状态不应变成“5–10人已验证”。
