## 证明边界

H3.2 与 Q1.3 的完整证明范围是非负、有界、逐次有限秩自由整数链以及任意阿贝尔系数。自然性同时处理链映射与系数群同态；杯积的系数自然性另要求环同态。空间的奇异链通常不是这个有限模型，因此已将胞腔上链比较作为独立引用，避免由同调群同构暗推上同调环结论。

Q2.2 仍为 Advanced Outline。未计算的对偶胞腔关联数符号没有写成已经成立的链等式；即使未来完成群对偶，还需比较到指定帽积映射。Euler 推论是依赖外引的完整代数推导，不提升对偶的证明状态。
