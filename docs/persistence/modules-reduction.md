# R1 · 持续模、区间与矩阵约化

<div class="chapter-meta">研究生课程 · 先修：K1、H3；域上线性映射<br>学习方式：先独立重构证明，再完成书面练习和即时自检。实验只检验指定有限输入。</div>

## 1. 直观解释

某尺度上有一个洞，不意味着它能与下一尺度的洞任意对应。持续同调同时保留群与包含诱导映射，条形码由这整套结构决定。

## 2. 严格定义

有限过滤 $K_0\subset\cdots\subset K_N$ 给持续模（persistence module）$V_i=H_k(K_i;\mathbb F_2)$ 及 $v_{ij}:V_i\to V_j$，满足复合律。区间模 $I[b,d)$ 在 $b\le i<d$ 时为一维，其余为零，区间内部映射为恒等。

实过滤值有重复时按“过滤值、维数、顶点序”排序，使面先于上单形。几何条形码使用左闭右开区间；未死亡类记 $d=+\infty$。只删除**精确相等端点**的零长度区间，任意正长度都保留。

## 3. 定理与证明

**引用定理（有限持续模分解与配对）。** 域上的有限维有限持续模唯一分解为区间模的直和（除顺序外）。按面先于上单形排列的边界矩阵，经只向后加列的标准约化后，非零列 $j$ 的最高非零行 $i$ 给出生—死亡配对 $(i,j)$；未配对的零列给无限条。完整证明需要过滤相容的链基变换，本章将其作为算法正确性定理引用，下面证明可独立检查的代数不变量和条形码结论。

**命题 R1.1（约化不变量与终止）。** 标准算法处理每列 $j$，只在已有列 $i<j$ 与当前列最高行相同时加该列，则始终 $R=DV$，其中 $V$ 为上三角且对角为一；过程有限终止，最终非零列 pivot 互异。
**证明。** 初始 $V=I$。每次同样的列加法施于 $V$，保持等式及上三角单位对角。模 2 相同最高行相加后消失，而更高行本来都零，所以该列最高行严格下降或整列为零；行数有限，故终止。停止条件正是最高行不与之前非零列冲突。$\square$

**命题 R1.2（秩与条形码）。** 若区间分解给条形码 $\mathcal B$，则

$$
\dim V_t=\#\{[b,d)\in\mathcal B:b\le t<d\},\qquad
\operatorname{rank}v_{st}=\#\{[b,d):b\le s\le t<d\}.
$$

**证明。** 直和上的映射逐区间作用，一个区间在两端都存在时贡献一个秩，否则贡献零。第一式取 $s=t$。$\square$

**推论。** 删除长度很短但非零的条，会在其存活尺度处改变 Betti 数，所以显示阈值不得用于核心计算。零长度条没有任何满足 $b\le t<d$ 的尺度，才可在实参数条形码中省略。

**数值语义。** 当前实现以 JavaScript binary64 距离计算的边出生值为输入；三角面出生为其边出生最大值。不再将距离舍入到 12 位小数，也不以 $10^{-10}$ 删除条。二进制浮点本身仍是近似，不能声称精确实数运算；可视标签的舍入不会回写核心过滤。

## 4. 正例与反例

**正例。** 两点相距 $10^{-10}$，边在 $5\cdot10^{-11}$ 出生，故 $\epsilon=0$ 时 $\beta_0=2$。薄矩形 $(0,0),(1,0),(1,10^{-5}),(0,10^{-5})$ 在 $0.5$ 到半对角线长度之间有正长度的一维条。

**反例。** 每个尺度群都一维的两个模，连接映射可以是恒等或零；前者一条长区间，后者两个短区间。只记录每个尺度的 Betti 数不能恢复持续模。
