# A8 · 可微持续同调：局部导数与配对切换

<div class="chapter-meta">研究生课程 · 内容状态：Reviewed（独立模型复核；非人类同行评审）<br>模型：固定有限单纯复形上的下星过滤；系数 F₂。局部可微定理不提供全局优化保证。</div>

## 1. 学习目标

本章结束后，你应能说明持续端点为什么在某些参数区域内可微，写出出生、死亡和寿命的链式法则；识别结构性等值、排序切换、配对切换与零长度事件；用一个四顶点模型证明损失在等值处不可微，并区分数学导数、分支梯度和数值差分。

## 2. 先修知识

- [A3 · 拓扑损失](topological-loss.md)：下星过滤、有限正条约定和目标 $L_m$。
- [R1 · 持续模与矩阵约化](../persistence/modules-reduction.md)：面先于单形的次序、边界矩阵和持续配对。
- [A1 · 持续特征](features-learning.md)：固定组合区域的初步可微性。
- 外部分析先修：$C^1$ 函数、Fréchet 可微性、方向导数、链式法则和最大值函数。自动微分（automatic differentiation）的基本机制可作为编程先修，但软件返回值不代替存在性证明。

## 3. 问题引入与直观解释：一条条形码的端点来自哪里

一维条形码看起来只含两个数字，但这两个数字是离散组合运算挑选的结果。在下星过滤中，先为每个单形选出最大值顶点，再排列单形并约化边界矩阵，最后选出出生—死亡配对。若这些选择暂时固定，端点就是固定的两个顶点输出；选择改变时，同一个公式未必继续适用。

因此，“持续同调能接入神经网络”不是“持续同调损失处处光滑”的同义句。本章逐步说明前者在什么局部条件下有严格依据，后者为什么一般不成立。

## 4. 严格定义

**定义 A8.1（参数化下星过滤）。** 固定有限单纯复形 $K$，令 $U\subset\mathbb R^p$ 为开集，$q_v:U\to\mathbb R$ 为 $C^1$ 顶点输出。设

$$
f_\theta(\sigma)=\max_{v\in\sigma}q_v(\theta).
$$

定义 $K_s(\theta)=\{\sigma:f_\theta(\sigma)\le s\}$。在与 A3 的分割损失相连时另要求所讨论区域的输出在 $[0,1]$，一般的局部端点定理不需要该归一化。

一个单形的**活动顶点（active vertex）**是实现上述最大值的顶点。本章求导定理要求在所讨论邻域内活动顶点唯一且不变。对单个顶点单形，此条件自动满足。

单形排序先比较过滤值，再按维数，最后按预先固定的顶点序比较；等值时面先于其上单形。这样的等值规则称为确定性破同值规则（deterministic tie-breaking）。它选定计算表示，不改变真实过滤中各单形同时进入的事实。

**定义 A8.2（固定组合区域）。** 在开邻域 $W\subset U$ 中，若所用单形的活动顶点、单形排列及约化采用的确定性规则均不变，则边界矩阵的排序和约化配对不变。损失若使用排序后的有限寿命，还须保证参与计算的正有限条不穿过零、所选排名身份不切换。

不要要求“所有单形过滤值两两不同”：一条边与其最大值端点必然具有相同出生值。这是下星过滤的结构性等值（structural tie），即使所有顶点值都不同也会出现。

**命题 A8.3（顶点严格排序给出的充分条件）。** 若在 $\theta_0\in U$ 处任意两个不同顶点的值都不相等，且各 $q_v$ 连续，则存在 $\theta_0$ 的开邻域 $W$，使每个单形的活动顶点和按定义 A8.1 的单形顺序固定。固定系数 $\mathbb F_2$ 和约化规则后，持续配对也固定。

**证明。** 有限多个非零差 $q_v(\theta_0)-q_w(\theta_0)$ 各在某个开邻域保持原符号；取这些邻域的有限交，得到一个开邻域 $W$，顶点的严格全序不变。每个单形包含固定顶点集合，其最高顶点因而固定。两个单形若最高顶点相同，过滤值在整个 $W$ 恒相等，用固定的维数和顶点序破同值；若最高顶点不同，其大小由固定的顶点序决定。因此排列固定。$K$ 的面关系固定，所以在该排列下的 $\mathbb F_2$ 边界矩阵逐项不变。确定性列约化对同一个矩阵执行同样步骤，主元和配对不变。$\square$

这只是充分条件；例如 A3 的两个端点恒为零，仍可在 $t>0$ 区域手工证明配对与端点公式不变。

**定理 A8.4（有限持续端点的局部可微性）。** 设 $q_v$ 为 $C^1$，在一个固定组合区域中，第 $i$ 条正有限持续条由单形 $\sigma_i$ 出生、$\tau_i$ 杀死；其活动顶点分别固定为 $u_i,w_i$。则

$$
b_i(\theta)=q_{u_i}(\theta),\qquad
d_i(\theta)=q_{w_i}(\theta),\qquad
\nabla\ell_i=\nabla q_{w_i}-\nabla q_{u_i}.
$$

这些函数是 $C^1$；若顶点输出光滑，则它们光滑。若 $\Phi$ 是这些端点的 $C^1$ 函数，则

$$
\nabla_\theta\Phi=
\sum_i\left(
\frac{\partial\Phi}{\partial b_i}\nabla q_{u_i}
+\frac{\partial\Phi}{\partial d_i}\nabla q_{w_i}
\right).
$$

**证明。** R1 所用的持续配对定理把区间端点标记为所配出生、死亡单形的过滤值。配对和活动顶点固定后，最大值表达式直接等于所列固定坐标输出。减法与有限维链式法则给出公式及 $C^1$ 性。证明使用的是选定区域内的表达式，不把离散约化步骤逐个当作可微映射。$\square$

这里引用 R1 明示的持续配对结果，未重新证明一般持续模分解定理。无限条的死亡不是一个有限实值函数，不能代入该有限端点公式。A3 的 $L_m$ 还需要有限寿命排名不切换；顶点严格排序本身不足以保证不同寿命的次序固定。

**命题 A8.5（四顶点路径的完整条形码）。** 对路径 $v_0-v_1-v_2-v_3$ 取 $q=(0,a,b,0)$，其中 $a,b\in[0,1]$，记 $c=\max\{a,b\}$。若 $c>0$，零维条形码为 $[0,+\infty)$ 与 $[0,c)$；若 $c=0$，只有无限条。$m=0$ 的有限寿命损失为

$$
L(a,b)=\max\{a,b\}^2.
$$

**证明。** $s<0$ 时没有顶点。设 $0\le s<c$。左右端点已经出现，而至少一个内部顶点尚未出现，因此两端未连通。内部顶点 $v_1$ 一出现即与 $v_0$ 通过边相连，$v_2$ 一出现即与 $v_3$ 相连；故不会产生第三个正持续分支。此时恰有两分支，它们在这个尺度范围内分别延伸而不合并。$s\ge c$ 时所有顶点与三条边均出现，恰有一个分支；合并映射秩为一，给出所列条形码。$c=0$ 时全路径同时出现。唯一正有限条的寿命为 $c$，没有有限条时为空和，故两种情况都给 $L=c^2$。$\square$

**命题 A8.6（相等值处不可微）。** 在开方形 $(0,1)^2$ 内，若 $a>b$，$\nabla L=(2a,0)$；若 $b>a$，$\nabla L=(0,2b)$。在 $a=b=c\in(0,1)$ 处，$L$ 不可微，甚至对任一单坐标的双侧偏导也不存在。沿任意方向 $h=(h_1,h_2)$ 的右方向导数为

$$
D_h^+L(c,c)=\lim_{t\downarrow0}\frac{L(c+th_1,c+th_2)-c^2}{t}
=2c\max\{h_1,h_2\}.
$$

**证明。** 严格大小关系保持于足够小邻域，前两种情况分别是 $a^2$ 和 $b^2$。在等值处固定 $b=c$：当 $h>0$ 时，关于 $a$ 的差商为 $((c+h)^2-c^2)/h=2c+h$；当 $h<0$ 时，$L(c+h,c)=c^2$，差商为 $0$。左右极限不同。对 $b$ 同理。对 $t>0$，最大值恰为 $c+t\max\{h_1,h_2\}$，展开平方得到方向公式。该公式不是关于 $h$ 的线性函数：在 $h=(1,0),(0,1)$ 都为 $2c$，在两者之和 $(1,1)$ 也为 $2c$，而不是 $4c$。故不存在可代表全部方向变化的经典梯度。$\square$

一个框架在相等处返回 $(2c,0)$、$(0,2c)$ 或按某种规则分配梯度，是所实现操作的约定。本文称它为分支或约定梯度，不笼统宣称任意持续损失的软件返回值都是 Clarke 次梯度。后者需要局部 Lipschitz 性、特定广义导数定义及额外论证。

## 6. 典型例题、正例与反例：哪些梯度可信

**基础例。** 在 $(a,b)=(0.7,0.3)$，有限寿命为 $0.7$，损失为 $0.49$，梯度为 $(1.4,0)$。小幅增大 $b$ 尚不改变端点；这不说明 $b$ 永远不影响损失，只说明当前局部区域由 $a$ 决定最大值。

**非平凡正例。** 在一个固定配对区域，设某有限条端点 $b(\theta)=\theta^2$、$d(\theta)=0.8$，$0<\theta<\sqrt{0.8}$，并假设该条已由实际固定复形配对产生。其抑制项为 $(0.8-\theta^2)^2$，导数为 $-4\theta(0.8-\theta^2)$。例如三顶点路径 $q=(0,0.8,\theta^2)$ 正好实现该有限条；另有无限条 $[0,+\infty)$。这里出生端点本身在移动，不是所有梯度都只经由死亡单形。

**常见错误反例。** 在 $(c,c)$ 使用中央差分近似对 $a$ 的偏导：取 $0<h<c$ 且 $c+h<1$，得到

$$
\frac{L(c+h,c)-L(c-h,c)}{2h}=c+\frac h2\longrightarrow c.
$$

这个极限存在，而双侧偏导不存在。中央差分看起来稳定，不足以证明目标在该点可微。

**综合计算。** 对 $a=b=0.5$，约定“相等时选左支”给 $(1,0)$。它对方向 $(0,1)$ 的线性预测为零，实际右方向导数为 $1$。沿 $(1,1)$ 实际导数也是 $1$，因而也不能把两个单坐标右导数拼成 $(1,1)$ 后用于所有方向。

ReLU 网络的输出一般不在全参数域 $C^1$。只有将网络激活模式固定在可微区域，再叠加本章过滤条件，才可直接应用 A8.4。网络激活切换和持续配对切换是两种不同的潜在不光滑来源。

## 7. 几何直观与原创图解

```text
下星过滤的选择链：
参数 θ → 顶点值 q_v → 单形的最大值顶点 → 单形排序 → 持续配对 → 端点损失
                         ↑                 ↑            ↑
                  选择固定才用本章局部链式法则；切换处另作分析

四顶点路径：  0          a          b          0
             v0 ------- v1 ------- v2 ------- v3
两端合并：               s = max(a,b)

参数方形：  b > a：L = b²   |   a = b：折线   |   a > b：L = a²
```

这里的“折线”描述参数平面中的切换集合，目标曲面沿该线形成折痕，不表示空间里的纽结或孔洞。A8.5 的过滤允许内部顶点与邻边同时出现，这些结构性等值不妨碍直接推导条形码。

## 8. 编程实验：分支梯度与差分

使用[拓扑学习实验室：可微边界](../labs/ai-topology.md#differentiable)，比较 $a>b$、$a<b$、$a=b>0$ 和 $a=b=0$。浏览器显示解析分支，并在非零等值处给出解析左右导数，不把破同值约定命名为“真实梯度”。下面的 Python 参照代码另外计算左右及中央差分，用来检验 A8.6 的有限步长表达式。

```python
from math import isfinite

def path_loss(a, b):
    if not all(isfinite(x) and 0 <= x <= 1 for x in (a, b)):
        raise ValueError("需要 0 <= a,b <= 1 的有限输入")
    return max(a, b) ** 2

def branch_gradient(a, b):
    path_loss(a, b)  # 验证定义域
    if a == b:
        return None  # 不把破同值约定冒充经典梯度
    return (2 * a, 0.0) if a > b else (0.0, 2 * b)

c, h = 0.5, 1e-4
right = (path_loss(c + h, c) - path_loss(c, c)) / h
left = (path_loss(c, c) - path_loss(c - h, c)) / h
central = (path_loss(c + h, c) - path_loss(c - h, c)) / (2 * h)
print(right, left, central)  # 分别接近 1、0、0.5
assert branch_gradient(0.75, 0.25) == (1.5, 0.0)
assert branch_gradient(0.5, 0.5) is None
```

这段代码只计算已证明的路径模型。函数在 $(0,0)$ 可以有零导数的延拓，但这个保守接口仍把等值统一返回 `None`；接口是否提供导数与数学上导数是否存在是两个问题。有限差分还受舍入和步长影响，不能用接近零的数值差分推断条形码没有短正区间。

## 9. 课后习题 { #a8-exercises }

1. **基础。** 对一条边两端点值 $q_0<q_1$，写出三个单形的过滤值。解释为什么“全部单形值互异”不是合适的下星过滤假设。
2. **证明。** 补充 A8.3：说明在所构造邻域中，一对配对单形若在 $\theta_0$ 给出零寿命，它为何保持零；若给出正寿命，它为何保持正。
3. **计算。** 对三顶点路径 $q=(0,0.8,\theta^2)$，$0<\theta<\sqrt{0.8}$，求有限条及 $L_0$ 对 $\theta$ 的导数。在 $\theta=0.5$ 处给出精确值。
4. **边界情况。** 对 A8.5 取 $(a,b)=(0,0),(0,0.4),(0.6,0.2),(0.3,0.3)$，列出正有限条、$s=0$ 和 $s=\max(a,b)$ 时的 $\beta_0$，以及适用时的梯度。
5. **反例。** 对 $c\in(0,1)$ 严格计算中央差分、左右差分的极限，说明为何中央差分收敛不能证明偏导存在。
6. **证明。** 用 A8.6 的方向导数证明不存在一个向量 $g\in\mathbb R^2$，同时满足 $D_h^+L(c,c)=g\cdot h$ 对全部 $h$ 成立。
7. **综合。** 写出用 A8.4 为神经网络损失反传所需的局部检查条件。构造一个顶点次序严格而两条寿命排序交换的有限过滤例子，说明排名条件不可省略。
8. **挑战。** 对 $F(a,b)=\max(a,b)^2$ 在整个 $\mathbb R^2$ 的延拓，证明 $F$ 在 $(0,0)$ Fréchet 可微且导数为零。解释为什么这不与非零对角线处的不可微性矛盾，也不使程序在所有等值处的某个统一梯度约定自动正确。

??? tip "提示 1：将连续与组合问题分开"
    1：边与高值端点共享值。2：比较两个活动顶点是否相同。3：有限类从较晚端点出生。4：先取最大值；零寿命不计。5：分清分母 $h$ 与 $2h$。6：只需三个方向。7：不同端点差可以相等，尽管端点本身各不相等。8：控制 $|F(a,b)|$ 与欧氏范数平方。

??? tip "提示 2：检查最易漏掉的边界"

## 11. 本章总结

在固定组合区域中，持续端点只是固定的顶点函数，链式法则具有明确数学依据。跨越最大值、配对或排名切换边界，需要重新分析。局部导数的存在不证明整体目标处处可微、不证明优化成功，也不证明一个库实现了它声称的过滤和配对；这些是独立的数学与工程检查任务。
