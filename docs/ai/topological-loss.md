## 3. 问题引入与直观解释：为什么数清孔洞还不够

设分割模型给每个网格顶点一个前景分数 $p_v\in[0,1]$。一条细桥上的分数稍低，就可能把一段预测血管分成两个分支。直接惩罚“连通分支数不等于目标值”符合直觉，却不一定提供可用于梯度下降的方向：只要所有分数仍在阈值的同一侧，二值结构根本不变。

持续同调（persistent homology）记录特征何时出现、何时消失，可把某些离散变化转成端点的连续变化。但转换后优化的是另一个目标。本章用三个顶点说明它的作用，也给出它不能保证的性质。真实任务的目标拓扑必须由任务定义、标注协议及有效性检查决定；不能把“每幅血管图都应连通且无环”设成普遍医学事实。

## 4. 严格定义

**定义 A3.1（下星过滤，lower-star filtration）。** 固定一个非空有限单纯复形 $K$，顶点集为 $V$。顶点值为 $q_v=1-p_v\in[0,1]$。对非空单形 $\sigma$ 设

$$
f_q(\sigma)=\max_{v\in\sigma}q_v,\qquad
K_s(q)=\{\sigma\in K:f_q(\sigma)\le s\},\quad s\in\mathbb R.
$$

面 $\tau\subseteq\sigma$ 满足 $f_q(\tau)\le f_q(\sigma)$，因此 $K_s(q)$ 是子复形，且 $s\le t$ 时 $K_s\subseteq K_t$。当 $s<0$ 时它为空，$s\ge1$ 时等于 $K$。顶点进入条件等价于 $p_v\ge1-s$；边和更高维单形要求其全部顶点进入。

固定 $k\ge0$，本章只使用 $H_k(-;\mathbb F_2)$，令 $\beta_k=\dim_{\mathbb F_2}H_k$，空复形的普通 $\beta_0$ 为 $0$。更换像素邻接关系、三角剖分、立方复形或系数域，可能更换计算对象；本文不能无说明地替代那些模型。

**定义 A3.2（硬阈值损失，hard-threshold loss）。** 对指定阈值 $s$、目标整数 $r\ge0$，设

$$
L_{\mathrm{hard}}(q;s,r)=\bigl(\beta_k(K_s(q))-r\bigr)^2.
$$

**定义 A3.3（有限条寿命损失，finite-bar lifespan loss）。** 对上述过滤的固定维数 $k$，取全部正长度有限持续条 $[b_i,d_i)$，$i=1,\ldots,N$。记寿命 $\ell_i=d_i-b_i>0$，按寿命降序排列。因过滤值位于 $[0,1]$，有 $\ell_i\le1$。对整数 $0\le m\le N$ 定义

$$
L_m(q)=\sum_{i=1}^{m}(1-\ell_i)^2+
\sum_{i=m+1}^{N}\ell_i^2.
$$

这是一种**特定教学损失**：鼓励最长的 $m$ 条寿命趋近 $1$，其余趋近 $0$。$m$ 是希望保留的有限条数，不能不加说明地等同于某阈值的 Betti 数。相同寿命在排名边界交换不会改变损失值，但可能改变用于求导的分支。

无限条 $[b,+\infty)$ 单独记录，不裁剪为 $[b,1)$ 后代入上述公式。它们反映最终复形 $K$ 的同调。固定连通 $K$ 的零维无限条始终有一条，不能把它当成一个需删除的额外分支。

若 $m=0,N=0$，空和为 $0$；任何正短条仍是求和项。若 $m>0$ 而 $N<m$，本章约定下公式不适用：需要另外设计并声明缺类惩罚或候选槽位模型。该公式本身不提供凭空创造缺失特征的保证。核心条形码只删除真正零长度条，不使用显示容差。

## 5. 定理与证明

**命题 A3.4（硬阈值的局部常值性）。** 固定 $s$。若 $q_v\ne s$ 对所有 $v\in V$ 成立，则 $q$ 在 $[0,1]^V$ 中有一个相对邻域，使 $K_s$ 和 $L_{\mathrm{hard}}$ 保持不变。若 $q$ 位于开立方体内部，$L_{\mathrm{hard}}$ 在该邻域的梯度为零。

**证明。** 有限性给出 $\delta=\min_{v\in V}|q_v-s|>0$。取 $\|q'-q\|_\infty<\delta/2$，每个 $q'_v-s$ 与 $q_v-s$ 同号，故进入过滤的顶点集合相同。一个单形进入当且仅当它的全部顶点进入，因此子复形相同，同调和损失也相同。常数函数在开邻域内可微，梯度为零。$\square$

若 $q=q(\theta)$ 是连续网络输出，且在 $\theta_0$ 满足上述阈值裕度，连续性保证参数的足够小邻域也保持该子复形。这个结论不覆盖 $q_v=s$ 的切换点，不说明损失在全参数域连续或可微。

**命题 A3.5（三顶点桥接模型）。** 令 $K$ 是路径 $v_0-v_1-v_2$，顶点值 $q=(0,t,0)$，其中 $0\le t\le1$。当 $t>0$ 时，普通零维条形码恰为

$$
[0,+\infty),\qquad [0,t).
$$

当 $t=0$ 时仅有第一条。对 $0\le s\le1$，$\beta_0(K_s)=2$ 当且仅当 $s<t$，其余情况为 $1$；所有 $H_1(K_s)$ 都为零。

**证明。** $s<0$ 时为空。若 $t>0$ 且 $0\le s<t$，复形恰含两个端点，各给一个 $H_0$ 生成元；区间内的包含映射在这两个元上是恒等。$s\ge t$ 时，中点和两条边同时进入，图是一条连通路径。两个原分支在 $H_0$ 中的像相同，原 $H_0\cong\mathbb F_2^2$ 到新 $H_0\cong\mathbb F_2$ 的映射秩为一；其核由两端点之和生成。因此一个类持续无限，另一个在 $t$ 死亡。中点和连接边同时进入不产生正长度的新类。$t=0$ 时整个连通路径同时出现，没有正有限条。每一尺度都是森林，无非零一维循环，故 $H_1=0$。$\square$

**推论 A3.6（可导的桥接惩罚）。** 在 A3.5 中采用 $m=0$ 的有限条损失，有 $L_0(t)=t^2$，包括 $t=0$ 的空和情况。在 $0<t<1$ 内导数为 $2t$，两端使用相应单侧导数。

**证明。** $t>0$ 时唯一正有限寿命是 $t$；$t=0$ 时空和为零。所得函数是多项式 $t^2$ 在 $[0,1]$ 的限制，导数结论直接按差商成立。$\square$

**命题 A3.7（固定配对下的寿命梯度）。** 在一个参数开集上，若所用的 $N$ 条正有限条端点 $b_i(\theta),d_i(\theta)$ 可微且配对、排序不变，则

$$
\nabla L_m=
\sum_{i\le m}2(\ell_i-1)(\nabla d_i-\nabla b_i)
+\sum_{i>m}2\ell_i(\nabla d_i-\nabla b_i).
$$

**证明。** 固定排序使每个求和项的身份不变。$\nabla\ell_i=\nabla d_i-\nabla b_i$，分别对 $(1-\ell_i)^2$ 和 $\ell_i^2$ 用链式法则，再对有限和求导。$\square$

端点可微的充分条件在 [A8](differentiable-persistence.md) 中证明。以上不是对整个训练过程的收敛定理。

## 6. 典型例题：正例与反例

**基础例。** 在 A3.5 取 $t=0.6$。尺度 $s=0.4$ 的 $\beta_0=2$，$s=0.6$ 的 $\beta_0=1$，有限寿命损失为 $0.36$。死亡端点不属于半开条，不能把 $s=t$ 仍计成两个分支。

**非平凡正例。** 固定一个满足 A3.7 条件的区域，两条寿命为 $0.8,0.2$，$m=1$。损失为 $0.04+0.04=0.08$，对这两个寿命的偏导依次为 $-0.4,0.4$。独立改变寿命的理想情形下，下降方向延长第一条、缩短第二条；真实顶点参数可能同时影响多个端点，因此不能把这句话当作任意网络可独立控制每条的结论。

**常见错误反例：损失小不等于所有阈值正确。** 对任意 $\varepsilon>0$，选 $0<t<\min\{1,\sqrt\varepsilon\}$。则 $L_0=t^2<\varepsilon$，但在阈值 $s=0$ 仍有两个连通分支。损失趋零没有使每个正 $t$ 的该阈值拓扑已经正确。对于固定的正阈值，能否得到保证需要额外的阈值裕度和特征位置条件。

**几何反例。** 同一条四顶点路径上的值 $(0,t,0,0)$ 与 $(0,0,t,0)$，$t>0$，由反射互换，条形码与本章损失相同；阈值 $0\le s<t$ 时删除的是不同顶点。持续条没有记录这一空间定位差异。

**综合例：数据项与拓扑项可以冲突。** 在三顶点模型设数据项为 $(t-1)^2$，总目标为 $(t-1)^2+\lambda t^2$，$\lambda\ge0$。唯一极小点为 $t_*=1/(1+\lambda)$。每个有限 $\lambda$ 都有 $t_*>0$，故即使目标被精确最小化，阈值 $s=0$ 仍给两个分支。该例没有训练噪声，却已否定“加入拓扑损失就保证目标拓扑”的无条件说法。

## 7. 几何直观与原创图解

下图表示 A3.5 的单纯复形，不表示一张医学图像；边旁标的是出生值。

```text
顶点值：     0             t             0
            v0 ----t----  v1  ----t---- v2

0 ≤ s < t： v0                           v2     两个分支
s ≥ t：     v0 ---------- v1 ---------- v2     一个分支

H0 无限条： [0 ------------------------------------→
H0 有限条： [0 ----------- t)     （仅当 t > 0）
```

图中一条有限条表示两个分支合并时消失的一维向量空间方向，不能把它唯一指定为某个物理端点；同时出生时代表元选择依赖约定，区间多重集不依赖这种命名。

## 8. 编程实验：桥接、阈值与损失

打开[拓扑学习实验室：损失与阈值](../labs/ai-topology.md#loss)，调节输入 $t$，对照条形码、固定阈值 $s=0.5$ 的 $\beta_0$ 和损失。浏览器演示重点核对 $t=0$ 和 $t=0.5$。下面的 Python 解析参照实现允许另外指定任意有限 $s$，可检查 $s=0$ 与极小正 $t$；它不依赖第三方库，只适用于 A3.5 的模型，不能冒充一般持续同调算法。

```python
from math import isfinite

def bridge_reference(t, s):
    if not isfinite(t) or not 0 <= t <= 1 or not isfinite(s):
        raise ValueError("需要有限参数，且 0 <= t <= 1")
    finite_bars = [] if t == 0 else [(0.0, t)]
    beta0 = 0 if s < 0 else (2 if s < t else 1)
    return finite_bars, (0.0, float("inf")), beta0, t * t

assert bridge_reference(0.0, 0.0)[0] == []
assert bridge_reference(0.6, 0.6)[2] == 1
assert bridge_reference(1e-12, 0.0)[2] == 2
assert bridge_reference(1e-12, 0.0)[0] == [(0.0, 1e-12)]
```

计算层必须保留任意可表示的正短条。平方在极小浮点数上可能下溢为零，这不授权删除原始条，也不证明数学损失恰为零。实验结果应保留输入、浮点约定及运行记录；断言核对的是有限输入，A3.5 的一般论证仍来自书面证明。

## 9. 课后习题 { #a3-exercises }

1. **基础。** 对路径 $v_0-v_1-v_2$ 取 $q=(0.2,0.8,0.4)$，列出每个单形的出生值、零维条形码及 $s=0.4,0.8$ 时的 Betti 数。
2. **证明。** 补全 A3.4 在参数输出 $q(\theta)$ 连续时的论证。解释为何“所有偏导几乎处处为零”不意味着损失全局为常数。
3. **边界情况。** 对 A3.5 的 $t=0,10^{-12},1$ 分别写出有限条、$L_0$ 和阈值 $s=0$ 的 $\beta_0$。解释为什么把 $10^{-12}$ 的条按容差删除会改变答案。
4. **计算。** 两条固定配对区间为 $[0.1,0.9)$、$[0.4,0.6)$，取 $m=1$。求损失及其对四个端点的偏导；注明计算使用的局部假设。
5. **证明。** 在定义 A3.3 的正有限条约定下，证明 $L_m=0$ 当且仅当 $N=m$ 且所有这 $m$ 条的寿命均为 $1$。包括 $m=N=0$。
6. **反例。** 为任意 $\varepsilon>0$ 构造 $L_0<\varepsilon$ 而 $s=0$ 时 $\beta_0\ne1$ 的桥接输入。这里的结论为何不否定持续图稳定性？
7. **综合。** 对四顶点路径上 $(0,t,0,0)$ 与 $(0,0,t,0)$，证明条形码相同，列出 $0\le s<t$ 时的两个子复形，并说明与一个固定位置标注比较时可能发生什么。
8. **挑战。** 在 $t\in[0,1]$ 上求 $(t-1)^2+\lambda t^2$ 的唯一极小点，讨论有限 $\lambda\ge0$ 和 $\lambda\to\infty$。区分参数极限、最小损失和固定阈值的 Betti 数。

??? tip "提示 1：先识别计算对象"
    1：边的出生是端点值的最大值。2：先选阈值裕度，再用有限个连续坐标。3：$[0,t)$ 在 $0$ 是否活跃取决于 $t$ 是否严格为正。4：先对寿命求导。5：非负平方和为零要求每项为零。6：让 $t$ 很小但不为零。7：使用路径反射。8：目标是严格凸二次式。

??? tip "提示 2：定位关键一步"
    1：较晚出现的分支在 $0.8$ 合并。2：切换集合外局部常数不约束跨越切换集合的值。4：$\partial\ell/\partial b=-1$、$\partial\ell/\partial d=1$。5：被压制的条按约定有严格正寿命。6：图可以靠近对角线而仍有一条正条。7：一个子复形缺 $v_1$，另一个缺 $v_2$。8：完成平方后检查 $t_*$ 在约束区间内。

## 11. 本章总结

拓扑损失必须声明复形、过滤、系数、有限条规则和目标语义。固定阈值的 Betti 数局部不变，而某些持续端点可在固定组合区域内求导。这提供一种训练信号，不提供几何位置、Dice、IoU、优化成功或医学合理性的普遍保证。[A8 · 可微持续同调](differentiable-persistence.md)进一步分析端点导数成立的条件及相等值处的不可微性。
