# 拓扑与人工智能

拓扑与人工智能（topology and artificial intelligence）建立在可说明的表示、假设和评价协议之上。它是理论与实验结合的独立路径末段，不以“拓扑特征天然更好”为前提。

## 本模块的写作计划

原计划已落成 A1、A2 和 [Notebook 04](../labs/index.md#learning)：景观稳定性、总寿命条件界、局部可微条件、无泄漏标准化以及同一模型下的几何/拓扑/联合特征比较。此标题保留以兼容旧锚点。

固定种子实验有 64 个训练点云、32 个测试点云；几何、拓扑、联合特征准确率分别为 30/32、31/32、31/32。它只描述一次合成数据划分，未做真实数据、多种子统计或外部泛化验证。未来调参须增加验证集，不能反复选择测试结果。
