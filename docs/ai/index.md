# 拓扑与人工智能

**核心问题：** 形状信息何时能改善数据表示与预测？

拓扑数据分析（topological data analysis, TDA）将数据的形状结构转成描述量。与人工智能（artificial intelligence, AI）的结合可以从一条明确流程开始：选择表示与度量 → 构造滤过 → 提取拓扑描述 → 输入学习模型 → 评估泛化。
