核对答案时至少记录：用了哪些假设；每个存在对象如何选；反方向是否成立；是否有一个满足前提但推翻结论的例子。发现错误请在[数学问题模板](https://github.com/Kevin20041008/topology-from-zero/issues/new?template=math-issue.yml)附章代码、题号、自己的推导和具体失败步骤。
