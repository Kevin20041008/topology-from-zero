## PRE1 · 逆像的包含关系能反映什么？ {#pre1}

[回到对应章节](../preliminaries/sets-maps-relations.md)。**先修：**映射、像、逆像、单射与满射；不要求拓扑。

### 层 1 · 先写目标、量词与假设

**待证命题。**设 f:X→Y、A⊆X、B⊆Y。证明 f(A)⊆B 当且仅当 A⊆f⁻¹(B)。

先回答：证明结束时应得到什么？先固定哪个任意对象，后选择哪个见证？哪条假设会在何处用到？若集合或指标为空，如何处理？

??? info "核对目标、量词与假设"
    - **目标：**“当且仅当”需要两个包含推理方向；不是证明 f 存在反函数。
    - **量词：**任意给定 f、A、B 后论证成立；第一个方向任取 x∈A，第二个方向任取 y∈f(A)。
    - **假设：**不要求单射、满射或非空；空 A 时两边都成立。

### 层 2 · 排序、排错并补上理由

交互组件下方保留同一组静态材料。步骤的字母只是标识；请说明每一步依赖什么，再排成证明。可交换的独立方向不强制唯一顺序。

<div data-proof-training="pre1"></div>
<noscript>交互区未启用；请用以下静态步骤纸笔作答，迁移题与完整答案不受影响。</noscript>

- **步骤 bad：**因为出现 f⁻¹，所以 f 必为双射。
- **步骤 d：**这个 x 属于 f⁻¹(B)，所以 y=f(x)∈B；任意 y 均如此，得 f(A)⊆B。
- **步骤 c：**反向设 A⊆f⁻¹(B)，任取 y∈f(A)，由像的定义存在 x∈A 使 y=f(x)。
- **步骤 b：**由 f(x)∈f(A)⊆B 得 x∈f⁻¹(B)，于是 A⊆f⁻¹(B)。
- **步骤 a：**先设 f(A)⊆B，任取 x∈A。

??? tip "逐步理由与错误反馈"
    - **a：**固定任意输入，用包含关系证明 A⊆f⁻¹(B)。 这一方向可以先开始。
    - **b：**逆像的定义只检查 f(x) 是否属于 B。 在此组织中先用步骤 a。
    - **c：**这里选取的是当前 y 的一个见证，不是假设反函数。 这一方向可以先开始。
    - **d：**由见证满足的条件得到输出的包含。 在此组织中先用步骤 c。
    - **bad：**应排除。逆像符号不表示反函数。常值函数也有每个子集的逆像；此步骤应排除。

**缺假设或错误推断的具体反例：**取 X={0}、Y={0,1}、f(0)=0。B={1}、C=∅ 的逆像相同，而 B⊄C。

### 层 3 · 新迁移证明（独立作答）

**任务。**证明：f:X→Y 满射，当且仅当对每对 B,C⊆Y，f⁻¹(B)⊆f⁻¹(C) 蕴含 B⊆C。给出非满射时失败的明确见证，处理 X 或 Y 为空的情况。

在纸上或上方写作区写出连贯论证。暂不看完整答案；可以明确记下自己尚不能证明的步骤。参考论证不是唯一合法写法，新的证明路径应交给同学或教师逐步核查。

??? tip "提示 1"
    正向：任取 y∈B，怎样把它转成可以使用逆像包含的输入？

??? tip "提示 2"
    反向：若 y₀ 不在 f(X) 内，比较 B={y₀} 与 C=∅。

**自核量规（只用于自评）：**

- 写明前提对每一对 B,C 成立，而不只是挑选的一对。
- 正向确实使用满射为任意 y∈B 找原像。
- 逆向使用遗漏点和空集，验证两个逆像均为空。
- 空集情形由同一论证涵盖，没有从空集合强行取点。

??? success "完整论证与边界情况（先独立作答）"
    若 f 满射，设 f⁻¹(B)⊆f⁻¹(C)。任取 y∈B，由满射取 x∈X 使 f(x)=y。于是 x∈f⁻¹(B)⊆f⁻¹(C)，所以 y∈C，得到 B⊆C。

    反向，假设所有 B,C 都满足所述蕴含。若 f 不满射，存在 y₀∈Y∖f(X)。取 B={y₀}、C=∅，两者逆像均为空，包含前提成立，但 B 不包含于 C，矛盾。因此 f 满射。

    若 Y=∅，函数的存在迫使 X=∅，结论成立；若 X=∅ 而 Y≠∅，遗漏点反例照样适用。这也说明不能只从某一对逆像相等推出 f 满射。

**参考定位。**PRE1.5–PRE1.7；Munkres, Topology, 2nd ed., Chapter 1 的集合与函数部分。 本题表述、推导组织与反馈为原创；没有声称逐页核查原书。

## PRE2 · 逆否证明与双向分类 {#pre2}

[回到对应章节](../preliminaries/proofs-counterexamples.md)。**先修：**整数奇偶性：每个整数恰为 2k 或 2k+1；逆否与逆命题的区别。

### 层 1 · 先写目标、量词与假设

**待证命题。**对每个整数 n，若 n² 为奇数，则 n 为奇数。用逆否证明，指出为何证明逆命题不能替代它。

先回答：证明结束时应得到什么？先固定哪个任意对象，后选择哪个见证？哪条假设会在何处用到？若集合或指标为空，如何处理？

??? info "核对目标、量词与假设"
    - **目标：**原命题是 n² 奇⇒n 奇；逆否为 n 偶⇒n² 偶，而逆命题是 n 奇⇒n² 奇。
    - **量词：**n 遍历整数；“n 偶”展开为存在整数 k 使 n=2k。
    - **假设：**整数域保证奇偶二分；对任意实数直接说“偶数或奇数”没有定义依据。

### 层 2 · 排序、排错并补上理由

交互组件下方保留同一组静态材料。步骤的字母只是标识；请说明每一步依赖什么，再排成证明。可交换的独立方向不强制唯一顺序。

<div data-proof-training="pre2"></div>
<noscript>交互区未启用；请用以下静态步骤纸笔作答，迁移题与完整答案不受影响。</noscript>

- **步骤 bad：**n 奇时 n² 奇，因此原命题已经证明。
- **步骤 d：**逆否已证，因而 n² 奇蕴含 n 奇。
- **步骤 c：**n²=4k²=2(2k²)，且 2k²∈Z，所以 n² 偶。
- **步骤 b：**按偶数定义存在 k∈Z，使 n=2k。
- **步骤 a：**改证逆否：任取偶整数 n。

??? tip "逐步理由与错误反馈"
    - **a：**经典逻辑中蕴含与逆否等价。 这一方向可以先开始。
    - **b：**存在见证来自偶数假设。 在此组织中先用步骤 a。
    - **c：**不仅写出因子2，还需其另一因子为整数。 在此组织中先用步骤 b。
    - **d：**由奇偶二分识别两个否定条件，再返回原命题。 在此组织中先用步骤 c。
    - **bad：**应排除。这一步只给逆命题。逆命题可能也真，但它本身不是原方向的证明。

**缺假设或错误推断的具体反例：**P⇒Q 与 Q⇒P 不能互换：实数 n=−1 满足 n²=1，却不满足 n=1。

### 层 3 · 新迁移证明（独立作答）

**任务。**对整数 a,b，证明 a²+b² 为奇数，当且仅当 a,b 恰有一个为奇数。必须证明两个方向，并用一个例子反驳“a²+b² 为偶数就说明 a,b 都偶”。

在纸上或上方写作区写出连贯论证。暂不看完整答案；可以明确记下自己尚不能证明的步骤。参考论证不是唯一合法写法，新的证明路径应交给同学或教师逐步核查。

??? tip "提示 1"
    先证明每个整数 t 的 t² 与 t 同奇偶；不要只列举几个 t。

??? tip "提示 2"
    在 a,b 都偶、都奇、恰一奇三种情况下计算平方和的奇偶。

**自核量规（只用于自评）：**

- 用 2k/2k+1 推出平方的奇偶规则。
- 覆盖且只需覆盖两数同偶、同奇、异奇偶三类。
- 明确必要性排除同奇偶，充分性处理异奇偶。
- 反例同时满足平方和偶与“并非都偶”，例如 a=b=1。

??? success "完整论证与边界情况（先独立作答）"
    若 t=2k，则 t²=2(2k²) 偶；若 t=2k+1，则 t²=2(2k²+2k)+1 奇。因此平方保持整数的奇偶性。

    若 a,b 恰一奇，则平方也恰一奇，偶整数与奇整数之和为奇整数，给充分性。若平方和奇而 a,b 同偶，则两平方都偶，和偶，矛盾；若二者同奇，则两平方都奇，和为 2(r+s+1)，仍偶，矛盾。整数奇偶二分排除了其余情况，所以恰一奇，给必要性。

    取 a=b=1，平方和为2而两数都奇，反驳指定错误推断。有限实例只负责反例，前两个段落才证明全称结论。

**参考定位。**PRE2.4 的逆否规则；整数计算仅用定义与分配律。 本题表述、推导组织与反馈为原创；没有声称逐页核查原书。

## PRE3 · 从一个点的剩余半径到集合的开邻域 {#pre3}

[回到对应章节](../preliminaries/metric-spaces.md)。**先修：**度量三角不等式、开球、度量开集的逐点定义。

### 层 1 · 先写目标、量词与假设

**待证命题。**在度量空间 (X,d) 中，a∈X、r≥0。证明闭球 F={x:d(x,a)≤r} 的补集开放。

先回答：证明结束时应得到什么？先固定哪个任意对象，后选择哪个见证？哪条假设会在何处用到？若集合或指标为空，如何处理？

??? info "核对目标、量词与假设"
    - **目标：**对每个 x∉F，找依赖于 x 的 s>0，使 B(x,s) 全在补集。
    - **量词：**先给定 x，再取 s，最后对每个 y∈B(x,s) 证明；不能交换成全体 x 共用一个 s。
    - **假设：**x∉F 给 d(x,a)>r，严格不等号保证 s=d(x,a)−r 正。

### 层 2 · 排序、排错并补上理由

交互组件下方保留同一组静态材料。步骤的字母只是标识；请说明每一步依赖什么，再排成证明。可交换的独立方向不强制唯一顺序。

<div data-proof-training="pre3"></div>
<noscript>交互区未启用；请用以下静态步骤纸笔作答，迁移题与完整答案不受影响。</noscript>

- **步骤 bad：**对所有 x∉F 统一取 s=1，因为每个点离 F 都有正距离。
- **步骤 d：**故 B(x,s)⊆X∖F；每个补集点均有这样的球，补集开放。
- **步骤 c：**由 d(x,a)≤d(x,y)+d(y,a)，得 d(y,a)≥d(x,a)−d(x,y)>r。
- **步骤 b：**任取 y∈B(x,s)，于是 d(x,y)<s。
- **步骤 a：**任取 x∉F，令 s=d(x,a)−r>0。

??? tip "逐步理由与错误反馈"
    - **a：**需要先固定补集中的点，才能确定正剩余距离。 这一方向可以先开始。
    - **b：**验证整个球的包含，不能只验证球心。 在此组织中先用步骤 a。
    - **c：**三角不等式移项；严格号来自球的定义。 在此组织中先用步骤 b。
    - **d：**这是开集的逐点定义。 在此组织中先用步骤 c。
    - **bad：**应排除。逐点正距离没有统一下界。R 中 F=[−1,1]，点 x=1.1 的半径1球会遇到 F。

**缺假设或错误推断的具体反例：**在 R 中点 x=1+1/n 都在闭球 [−1,1] 外，但剩余距离1/n趋于0，不能用逐点存在推出统一半径。

### 层 3 · 新迁移证明（独立作答）

**任务。**给任意 A⊆X 及 r>0，令 Uᵣ(A)={x∈X:存在 a∈A 使 d(x,a)<r}。不直接引用“开球的任意并开放”，逐点证明 Uᵣ(A) 开放；处理 A=∅。说明把 < 改为 ≤ 后集合不一定开放。

在纸上或上方写作区写出连贯论证。暂不看完整答案；可以明确记下自己尚不能证明的步骤。参考论证不是唯一合法写法，新的证明路径应交给同学或教师逐步核查。

??? tip "提示 1"
    固定 x 后，只为这个 x 取一个见证 a；令 s=r−d(x,a)。

??? tip "提示 2"
    反例可取通常实数空间、A={0}、r=1。

**自核量规（只用于自评）：**

- 固定任意 x∈Uᵣ(A) 后才选 a∈A。
- 剩余半径严格正，并对任意 y∈B(x,s) 使用三角不等式。
- 用同一个见证 a 证明 y∈Uᵣ(A)，不要求最近点存在。
- 空 A 给空集；≤ 的反例具体说明哪个点没有内部球。

??? success "完整论证与边界情况（先独立作答）"
    若 A=∅，Uᵣ(A)=∅，按开集定义开放。一般情形任取 x∈Uᵣ(A)，存在 a∈A 使 d(x,a)<r。令 s=r−d(x,a)>0。

    任取 y∈B(x,s)，有 d(y,a)≤d(y,x)+d(x,a)<s+d(x,a)=r。因此同一个 a 证明 y∈Uᵣ(A)，得到 B(x,s)⊆Uᵣ(A)。对每个 x 这样构造便证明开放；没有使用最近点或同时选择全部见证。

    若把不等号换为≤，取 X=R、A={0}、r=1 得 [−1,1]。任何以1为中心的正半径球都含大于1的点，所以该集合不开放。

**缺假设或错误推断的具体反例：**不能因 K 紧就断言 K 在任意 X 中闭：两点平凡拓扑空间的单点紧却不闭。指导证明无需这一步。

### 层 3 · 新迁移证明（独立作答）

**任务。**有限闭集粘合：设 X=A∪B，A、B 在 X 中闭。连续 f:A→Y、g:B→Y 在 A∩B 相等。证明逐块定义的 h:X→Y 连续；Y 不要求 Hausdorff。再以 R 的单点闭覆盖和一个不连续函数说明不能无条件改成无限闭覆盖。

??? tip "提示 1"
    先由相交处相等证明 h 是函数。用补集证明连续性也可由闭集逆像判定。

??? tip "提示 2"
    对 Y 中闭集 F，h⁻¹(F)=f⁻¹(F)∪g⁻¹(F)。怎样从相对闭变成 X 中闭？

**自核量规（只用于自评）：**

- 先确认两条规则在交上无冲突，且覆盖全部 X。
- 解释连续的闭集逆像判据，而非擅自从“开”替换为“闭”。
- 分别利用 A、B 在 X 闭及 PS1 闭传递，再取有限并。
- 无限覆盖反例检查每块限制连续、块闭、总函数不连续。

??? success "完整论证与边界情况（先独立作答）"
    覆盖和交上相等保证 h 每处有唯一函数值。对任意连续 k:Z→Y 和 Y 中闭 F，Z∖k⁻¹(F)=k⁻¹(Y∖F) 开，故闭集逆像闭；反向通过同样补集恒等式也成立，所以可用闭集判据。

    任取 Y 中闭 F。f⁻¹(F) 在 A 中闭，且 A 在 X 中闭，故 f⁻¹(F) 在 X 中闭；g⁻¹(F) 同理。集合 h⁻¹(F)=f⁻¹(F)∪g⁻¹(F) 是两个环境闭集的并，仍闭。闭集逆像判据给 h 连续，没有使用 Y 的分离条件。

    无限版本失败：用通常实数空间的所有单点 {x} 闭覆盖 R。令 h(0)=1、h(x)=0（x≠0）。每个单点限制连续，交上条件成立；但 h⁻¹((1/2,3/2))={0} 不开，所以 h 不连续。失败处是无限个闭集的并未必闭。

## connectedness · 连通空间不能被离散标签分开 {#connectedness}

[回到对应章节](../point-set/connectedness.md)。**先修：**分离、连续逆像、子空间开集与闭包。

### 层 1 · 先写目标、量词与假设

**待证命题。**若 X 连通、D 离散且 f:X→D 连续，证明 f(X) 至多一个点。允许 X=∅。

先回答：证明结束时应得到什么？先固定哪个任意对象，后选择哪个见证？哪条假设会在何处用到？若集合或指标为空，如何处理？

??? info "核对目标、量词与假设"
    - **目标：**“至多一个点”包括空像；不写无条件存在某个常值 d∈D。
    - **量词：**若像里有两个不同值，选择其中一个的纤维和它的补集。
    - **假设：**D 离散使单点及其补集开，连续使逆像开，连通排除两块都非空。

### 层 2 · 排序、排错并补上理由

- **步骤 bad：**只要 f 连续，其像就必为一个点，与定义域是否连通无关。
- **步骤 d：**与 X 连通矛盾，故像至多一点；X 空时像空，结论也成立。
- **步骤 c：**U、V 非空、不交且并为 X，构成分离。
- **步骤 b：**D 离散且 f 连续，所以 U、V 在 X 开。

    - **a：**选择像中的值保证两个逆像都有见证。 这一方向可以先开始。
    - **b：**每个目标子集开放，通过连续性拉回。 在此组织中先用步骤 a。

    - **d：**排除两个不同像点，不需假定定义域非空。 在此组织中先用步骤 c。
    - **bad：**应排除。两点离散空间到自身的恒等映射连续且像有两点；连通性是关键条件。

**缺假设或错误推断的具体反例：**若去掉目标离散条件，连通区间 [0,1] 到自身的恒等映射连续，像不止一点。

### 层 3 · 新迁移证明（独立作答）

**任务。**设 A 是 X 的连通子集，且 A⊆B⊆cl_X(A)。证明 B 连通。处理 A=∅，并给出取消 B⊆cl_X(A) 后失败的反例。

在纸上或上方写作区写出连贯论证。暂不看完整答案；可以明确记下自己尚不能证明的步骤。参考论证不是唯一合法写法，新的证明路径应交给同学或教师逐步核查。

??? tip "提示 1"
    若 B 有相对开分离 U,V，说明每个非空部分都遇到 A。

??? tip "提示 2"
    将 U 写成 B∩O；取其中一点 x，利用 x∈cl_X(A)。

**自核量规（只用于自评）：**

- 明确连通与分离都在相应子空间拓扑中讨论。
- 证明非空分离部分遇到 A，使用 B⊆cl_X(A) 以及 A⊆B 两个包含。
- 将分离限制到 A，核对非空、开、不交、覆盖四项。
- 处理空 A；反例保留 A 连通及 A⊆B，只去掉上界条件。

??? success "完整论证与边界情况（先独立作答）"
    若 A=∅，其闭包为空，两个包含迫使 B=∅，按约定连通。否则假设 B=U∪V 为分离。取 x∈U，写 U=B∩O，其中 O 在 X 开且含 x。由于 x∈B⊆cl_X(A)，有 O∩A≠∅；又 A⊆B，所以 O∩A=U∩A。因此 U∩A 非空。V 同理。

    两者在 A 中相对开、不交且并为 A，于是分离了 A，与 A 连通矛盾。因此 B 连通。这也包含 B=cl_X(A) 的闭包保持连通结论，但证明没有预先假定 B 本身连通。

    取消 B⊆cl_X(A)：取通常 R 中 A={0}、B={0,1}。A 连通且 A⊆B；B 中两个单点都相对开，构成分离，所以 B 不连通。
