# P4 · 紧致性、有限交性质与度量判据

<div class="chapter-meta">研究生课程 · 先修：第二章、P1–P3；实数完备性<br>学习方式：先独立重构证明，再完成书面练习和即时自检。实验只检验指定有限输入。</div>

## 1. 直观解释

紧致性的定义允许任意开覆盖。有限交性质把同一思想反过来描述为：有限次检查都不矛盾的闭条件，能同时满足。在度量空间里，紧致性还可以拆成“没有缺失极限”和“每个精度下只需有限个近似点”。

## 2. 严格定义

闭集族有有限交性质（finite intersection property，FIP），指每个有限子族的交非空。度量空间全有界（totally bounded），指对每个 $\varepsilon>0$ 可用有限个半径 $\varepsilon$ 的球覆盖。完备（complete）指每个 Cauchy 数列收敛于空间内；Cauchy 条件为对每个正误差，足够靠后的任意两项距离小于该误差。

序列紧致（sequentially compact）指每个数列有收敛子列，极限仍在空间中。本章证明它与紧致在度量空间中等价，不将其推广到所有拓扑空间。

## 3. 定理与证明

**定理 P4.1（FIP）。** $X$ 紧致当且仅当每个有 FIP 的闭集族总交非空。

**证明。** 取补集，把“总交为空”变成开覆盖，把“每个有限交非空”变成没有有限子覆盖。两个方向均由 De Morgan 律得到。空空间没有非空 FIP 族，约定与定义一致。$\square$

**定理 P4.2（紧致与分离）。** Hausdorff 空间的紧致子集闭。紧致 Hausdorff 空间正规；从紧致空间到 Hausdorff 空间的连续双射为同胚。

**证明。** 对紧致 $K$ 外一点 $x$，分别用不交开邻域分离 $x$ 与每个 $y\in K$。$K$ 一侧取有限子覆盖，$x$ 一侧取有限交，即得避开 $K$ 的邻域，所以 $K$ 闭。紧致空间的闭子集紧致（第二章练习 4 已给证明）。在紧致 Hausdorff 空间中分离不交闭集 $A,B$：上述有限操作先分离每个 $a\in A$ 与整个 $B$，然后在 $A$ 上再取有限子覆盖及 $B$ 一侧的有限交。得到不交开邻域，故正规。最后，连续双射把闭集送到紧致集，再送到闭集；其逆映射连续。$\square$

**定理 P4.3（度量紧致性三等价）。** 对度量空间，紧致、序列紧致、完备且全有界等价。

**证明。** 紧致立即给出有限球覆盖。对 Cauchy 数列，各尾集闭包在紧致空间中有 FIP，取交中一点 $x$。给 $\varepsilon>0$，足够靠后的项彼此距离小于 $\varepsilon/2$，而 $x$ 的 $\varepsilon/2$ 邻域遇到这条尾集，故所有足够靠后的项距 $x$ 小于 $\varepsilon$，从而完备。

完备且全有界时，对任意数列，逐次用半径 $2^{-k}$ 的有限球覆盖，在上一步保留的无限指标集中选择仍含无限项的一个球。依次选严格增大的指标，所得子列的足够靠后两项同处半径 $2^{-k}$ 的一个球，距离至多 $2^{1-k}$，故为 Cauchy 子列并收敛。

序列紧致首先蕴含全有界，否则可递归选出两两距离至少某个 $\varepsilon$ 的数列，不可能有收敛子列。再给任意开覆盖，证明存在 $\delta>0$ 使每个 $\delta$ 球包含于某个覆盖成员。否则对每个 $n$ 取 $x_n$，其半径 $1/n$ 的球不含于任一成员。收敛子列趋于 $x$，取覆盖成员包含 $B(x,r)$；充分靠后时相应 $1/n$ 球包含于 $B(x,r)$，矛盾。最后用有限个 $\delta$ 球覆盖，并分别选包含它的覆盖成员，即得到有限子覆盖。$\square$

**推论 P4.4（Heine–Borel）。** $\mathbb R^n$ 中子集紧致当且仅当闭且有界。

**证明。** 紧致集由 P4.2 闭；若无界，递增球覆盖没有有限子覆盖。反之，$\mathbb R^n$ 的完备性由各坐标的实数完备性得到，闭子集也完备。一个有界立方体可划分成有限个任意小直径的盒子；对每个遇到子集的盒子选其中一点，用稍大于盒子直径的球覆盖，故有界子集全有界。应用 P4.3。$\square$

## 4. 正例与反例

**正例。** Cantor 集可定义为 $[0,1]$ 中逐次删除中间开三分之一后剩余闭集的交；它闭且有界，故紧致。每一阶段的区间覆盖给出其全有界性，但紧致结论仍依赖极限点未被遗漏。

**反例。** 无限离散空间取距离 $d(x,y)=1$（$x\ne y$），它完备且有界，却不是全有界或紧致。因此一般度量空间中“有界”不能替代“全有界”。$(0,1)$ 全有界却不完备，数列 $1/n$ 的缺失极限说明不能省掉完备性。

## 5. 练习

1. 证明紧致度量空间连续实函数一致连续；定义域非空时取得最大、最小值。
2. 证明紧致空间中一列递减非空闭集的交非空。
3. 给出闭且有界但不紧致的度量空间；指出其失败的是哪个条件。

??? tip "提示 1"
    1：一致连续若失败，找距趋于零但函数值相差固定正数的两列点；再抽子列。最值使用连续像紧致及 P4.4。

??? tip "提示 2 与核对"
    1：若 $x_{n_k}\to x$ 且 $d(x_n,y_n)\to0$，则 $y_{n_k}\to x$，连续性造成矛盾。像为非空紧致实数集时，上确界属于该闭集。2：递减性给 FIP。3：使用上文无限离散度量；它缺少全有界性。
