# P9 · 局部连通、仿紧致与单位分解

<div class="chapter-meta">研究生课程 · 先修：基础 B、P2、P6、P7<br>学习方式：先独立重构证明，再完成书面练习和即时自检。实验只检验指定有限输入。</div>

## 1. 直观解释

连通性是整体条件；局部连通要求在任意小范围内也能找到连通邻域。单位分解则把局部构造拼成全局对象：每一点只涉及有限多个权重，所以无穷求和仍能逐点安全进行。后者是微分拓扑构造的先修。

## 2. 严格定义

局部连通（locally connected）指每点有连通开邻域基；局部道路连通（locally path connected）用道路连通开集替代。道路分支是“可用道路相连”关系的等价类。

集合族局部有限（locally finite），指每点有邻域只遇到有限多个成员。开覆盖的开加细（open refinement）仍覆盖空间，且每个成员包含于原覆盖某成员。仿紧致（paracompact）指每个开覆盖有局部有限开加细。

从属于开覆盖 $\mathcal U$ 的连续单位分解（partition of unity）为局部有限连续函数族 $\rho_j:X\to[0,1]$，使 $\sum_j\rho_j=1$，且每个支集 $\operatorname{supp}\rho_j=\overline{\{\rho_j\ne0\}}$ 包含于某个 $U\in\mathcal U$。

## 3. 定理与证明

**命题 P9.1。** 局部道路连通空间的道路分支开，并与连通分支相同。

**证明。** 道路分支中每点的道路连通开邻域仍在同一分支，所以分支开。其补集为其他开分支之并，故也闭。任何连通子集不能同时遇到一个开闭分支及其补集；而道路分支本身连通。因此两种最大分支相同。$\square$

**引理 P9.2。** 局部有限闭集族的并闭；局部有限集合族取闭包后仍局部有限。

**证明。** 在某点的局部有限开邻域中，只需处理有限个闭集。若该点在并外，去掉这有限个闭集仍得到避开并的开邻域。第二项因为开邻域若遇到某集合闭包，也必遇到原集合。$\square$

**定理 P9.3。** 仿紧致 Hausdorff 空间正规，并且每个开覆盖存在从属于它的连续单位分解。

**证明（正则性）。** 给 $x\in O$，对每个 $y\ne x$ 选不交开集 $V_y\ni x,W_y\ni y$。覆盖 $\{O\}\cup\{W_y\}$ 有局部有限开加细 $\mathcal R$。取 $x$ 的开邻域 $N$ 只遇有限多个加细成员。对其中不被指定在 $O$ 内的成员，取它所从属的 $W_y$，令 $V=N\cap\bigcap V_y$。若一个加细成员不遇 $N$，因它开，也不遇 $\overline V$；若它从属于列出的 $W_y$，也不遇 $\overline V$。故 $\overline V$ 只能落在指定从属 $O$ 的成员之并中，从而包含于 $O$。

**证明（正规性）。** 对不交闭集 $A,B$，用正则性选每个 $a$ 的开邻域 $U_a$，使闭包避开 $B$。加上 $X\setminus A$ 得开覆盖，取局部有限开加细。收集遇到 $A$ 的成员，其并 $V$ 含 $A$；这些成员只能从属某个 $U_a$。由 P9.2，$\overline V$ 为各闭包之并，避开 $B$。所以 $V$ 与 $X\setminus\overline V$ 分离二者。

**证明（单位分解）。** 先用正则性把原覆盖逐点缩小，再局部有限加细得 $W_j$，保证每个 $\overline W_j$ 包含于原覆盖一员。再次缩小并局部有限加细，得 $T_k$，且 $\overline T_k\subset W_{j(k)}$。令 $F_j=\bigcup_{j(k)=j}\overline T_k$。P9.2 保证 $F_j$ 闭，$F_j\subset W_j$，且它们覆盖 $X$。Urysohn 引理给 $f_j=1$ 于 $F_j$、$f_j=0$ 于 $X\setminus W_j$ 的连续 $[0,1]$ 值函数。函数族局部有限，其和 $s$ 连续且处处至少为 1。取 $\rho_j=f_j/s$，即得到所需单位分解，其支集包含于 $\overline W_j$。$\square$

**引用定理（Stone 仿紧致性）。** 每个度量空间仿紧致。本章没有证明该一般加细构造；可参阅 Willard 的仿紧致性部分。与 P7 合用，它说明第二可数 Hausdorff 流形满足本章单位分解的拓扑前提，光滑单位分解还需光滑局部函数。

## 4. 正例与反例

**正例。** 欧氏空间局部道路连通；流形的坐标小球给相同性质。有限开覆盖本身局部有限，但为了令支集真正包含于指定成员，仍须做缩小与函数构造。

**反例。** 基础 B 的闭正弦曲线连通却不道路连通，因此不可能局部道路连通。函数族逐点只有有限个非零项，不代表局部有限：三角尖峰的支集可不断趋近零点，使总和在零点不连续。

## 5. 练习

1. 证明局部连通空间的连通分支开。
2. 写出实数轴上支集趋近零点、峰高为一的连续函数族，说明逐点有限求和可能不连续。
3. 若单位分解从属于开覆盖，证明各局部常值数据能用它拼成连续实函数（数据先以支集控制的方式延拓）。

??? tip "提示 1"
    2：在互不相交的小区间内放三角尖峰，区间中心趋零。3：在支集外取零，局部有限性使总和局部是有限和。

??? tip "提示 2 与核对"
    2：可取中心 $2^{-n}$，支集半径 $2^{-n-2}$；总和在零点为零，在各中心为一。3：对常数 $c_j$，$\sum c_j\rho_j$ 连续，不需要这些常数有统一界，因为每点附近只出现有限项。
