# 点集拓扑

**核心问题：** 连续映射会保持空间的哪些性质？

点集拓扑（point-set topology）研究拓扑空间本身的结构。本模块先以连续和紧致为主线，练习用逆像转换问题，以及辨认定理中不能遗漏的假设。

- **现在可读：** [02 · 连续映射与紧致性](02-continuity.md)。
- **现在可做：** 在有限例子中区分连续双射与同胚。
- **后续范围：** 连通性、道路连通性、豪斯多夫空间、积拓扑与商拓扑。尚未形成完整课程。
- **先修：** [第一章](../introduction/01-spaces.md)；函数逆像的运算。

读完后应能独立重构紧致连续像定理的证明。后续的商空间将为粘合空间、基本群和曲面学习做准备；当前可先用线性代数进入[第三章的有限模型](../algebraic/03-homology.md)。
