# 拓扑学导论

**核心问题：** 不使用固定的距离，还能怎样描述一个点周围的结构？

本模块从集合与函数开始，把“附近”转成开集、邻域和拓扑公理。完成后应能验证有限集合上的拓扑，并解释为什么无穷交不能替代有限交。

- **现在可读：** [01 · 从距离到拓扑](01-spaces.md)。
- **现在可做：** [有限拓扑与连续映射实验](../labs/index.md#finite)。
- **接续阅读：** [基础 A · 拓扑基与子基](../point-set/bases-subbases.md)补充生成拓扑、子空间与有限积；内部与闭包的系统理论仍待补充。
- **先修：** 并、交、补集、函数；不要求微积分。

完成第一章习题后进入[点集拓扑](../point-set/index.md)。如果度量公理仍不熟悉，可先验证实数绝对值距离与离散度量。
