# C1 · 覆盖映射、提升与圆周基本群

<div class="chapter-meta">研究生课程 · 先修：基础 C、F1、P4；区间紧致性<br>学习方式：先独立重构证明，再完成书面练习和即时自检。实验只检验指定有限输入。</div>

## 1. 直观解释

覆盖空间在每个足够小区域内只是若干互不相交的副本；全局上，不同副本却能由绕行相互连接。提升把底空间的道路搬到选定的起点上，绕一圈后的落点记录了基本群信息。

## 2. 严格定义

覆盖映射（covering map）是连续满射 $p:E\to X$，使每个 $x$ 有开邻域 $U$，满足 $p^{-1}(U)=\coprod_\lambda V_\lambda$，其中各 $V_\lambda$ 开，$p|_{V_\lambda}:V_\lambda\to U$ 为同胚。$U$ 称均匀覆盖邻域（evenly covered neighborhood），$p^{-1}(x)$ 为纤维（fiber）。

提升（lift）$\widetilde f$ 满足 $p\widetilde f=f$。圆周按 $S^1=\{z\in\mathbb C:|z|=1\}$，指数覆盖为 $p(t)=e^{2\pi it}$。本章仅用连续映射，不使用复分析。

## 3. 定理与证明

**定理 C1.1（道路提升）。** 给道路 $\alpha:I\to X$ 和 $e_0\in p^{-1}(\alpha(0))$，存在唯一提升 $\widetilde\alpha$ 以 $e_0$ 为起点。

**证明。** 均匀覆盖邻域的逆像覆盖紧区间，Lebesgue 数给有限分割，使每个闭小区间的像落在一个均匀覆盖邻域。第一段用包含 $e_0$ 的片的逆映射定义提升，其终点决定下一片，递归后在端点处吻合，有限闭粘合给连续性。唯一性局部成立：同一时刻相等的两个提升在某共同小区间内都处于同一片，必须相等；不同值所在的片也使不等集合开。相等集合非空且开闭，区间连通迫使它为全集。$\square$

**定理 C1.2（方形提升）。** 给道路同伦 $H:I^2\to X$ 和其底边的一个提升，存在唯一方形提升。若原同伦固定道路端点，则提升的端点也固定。

**证明。** 拉回均匀覆盖邻域得到紧方形的开覆盖；取足够细的有限矩形网格，使每个闭小矩形的像在一个这样的邻域中。从底行向上、每行从左向右，使用已确定角点选择片并通过逆映射提升整个小矩形。若底边与左边均已确定，其提升因 C1.1 的唯一性都与该片内的提升一致，故可粘合。有限闭粘合给整体连续与唯一。端点对应方形左右边，其像为常值道路；纤维离散，常值道路的提升只能常值，所以端点固定。$\square$

**定理 C1.3。** $p_*:\pi_1(E,e_0)\to\pi_1(X,p(e_0))$ 单射。

**证明。** 若投影环路可端点固定地缩成常值，提升该方形同伦。底边是原环路，顶边为常值提升，左右边固定于 $e_0$，因此原环路也可缩。$\square$

**定理 C1.4。** $\pi_1(S^1,1)\cong\mathbb Z$。

**证明。** 指数映射在长度小于一的适当开区间上同胚到圆弧，故为覆盖。对以 1 为基点的环路，取起点为 0 的唯一提升，其终点为整数，称绕数（winding number）。C1.2 表明绕数在端点固定同伦下不变。拼接提升时第二段平移第一个终点整数，故绕数相加。环路 $t\mapsto e^{2\pi int}$ 的绕数为 $n$，所以满射。绕数为零时提升是实数轴中基于零的环路，可由线性收缩固定端点地缩为常值；投影给原环路的收缩，所以核为零。$\square$

## 4. 正例与反例

**正例。** $z\mapsto z^n$（$n\ge1$）是圆周的 $n$ 片覆盖；其基本群映射把整数乘以 $n$。指数覆盖的总空间实数轴单连通（simply connected），即道路连通且基本群平凡。

**反例。** $z\mapsto z^2$ 从整个复平面到自身不是覆盖：零点附近存在分支点（branch point），零的纤维只有一个点，附近非零纤维有两个点，不可能局部同为若干片。

**反例。** 连续满射或局部“看起来展开”不足以代替均匀覆盖条件；必须检查整个逆像可分成映到同一个邻域的全部片。

## 5. 练习

1. 计算环路 $t\mapsto e^{6\pi it}$ 的绕数。
2. 证明次数不同的圆周幂映射不作为带基点映射同伦。
3. 证明闭圆盘不存在到其边界圆周的收缩映射。

??? tip "提示 1"
    2：比较诱导整数同态。3：圆盘基本群平凡，而收缩需要 F1 练习 2 的单射。

??? tip "提示 2 与核对"
    1：提升为 $3t$，终点 3。2：分别为乘以两个不同整数。3：不可能将 $\mathbb Z$ 单射到平凡群。
