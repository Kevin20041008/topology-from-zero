# 几何拓扑

几何拓扑（geometric topology）关注流形、嵌入、分解和粘合。路线 T1 → T2 → T3 → T4 从 TOP/PL/DIFF 范畴与链接开始，经过曲面、结补空间，再进入三维填充与配边。

每章区分已证明的局部/代数命题和引用的全局分类定理。紧曲面分类、Wirtinger 几何推导、三维手术表示、JSJ 与几何化的完整证明不在本轮已证范围。曲面的不变量、三叶结非平凡性及 Dehn 填充的一阶同调都有实际推导。
