# 计算拓扑

计算拓扑（computational topology）独立路径从有限链复形出发，与持续同调和 AI 课程相接。先修为线性代数与第三章；K1 的完整研究生论证还使用 H3。可先运行实验，再回到证明补齐理论。

## 目前可用的学习链条

**代数预备 → 第三章 → K1 → R1 → R2 → A1 → A2**。Notebook 02 手算有限同调，03 实算杯积，04 比较拓扑与几何特征。三维渲染模型与计算复形分开说明，核心持续算法保留全部正长度区间。

K1 给输入契约、秩公式、二维骨架范围、消元证书与复杂度；稀疏算法的性能工程和大数据基准尚未实现，不能把小点云演示当作性能承诺。
