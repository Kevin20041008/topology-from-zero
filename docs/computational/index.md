# 计算拓扑

**核心问题：** 一个拓扑定义怎样变成能检查、能复现的算法？

计算拓扑（computational topology）需要指定输入、构造规则和系数域。当前提供一个完整小型实验：从二维点云构造 Vietoris–Rips 复形的二维骨架，用模 2 消元计算 $\beta_0$ 和 $\beta_1$。

## 目前可用的学习链条

1. 阅读[第三章](../algebraic/03-homology.md)的定义、秩公式与手算例子。
2. 运行 [Notebook 02](../labs/index.md#homology)，检查 $D_1D_2=0$。
3. 对比孤立点、方环和填充后三种情形的 Betti 数。
4. 修改坐标与阈值，记录哪些结果来自度量选择。

本实验直接枚举所有边和三角形。对 $n$ 个点，候选三角形有 $\binom n3$ 个，适合教学规模，不适合作为大规模点云算法。

**后续章节计划：** 数据结构、稀疏边界矩阵、消元复杂度、与成熟库交叉验证。当前没有编写这些章节，也没有性能基准结果。
