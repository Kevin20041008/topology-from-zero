## 2. 存储、导航与无 JavaScript 回退

- `decodeProgress` 捕获非法 JSON，过滤未知路线、未知章节、非字符串 ID，并去重；不把任意本地存储字符串注入 HTML。
- 完成勾选幂等且可撤销；函数不原地改写先前状态。当前路线的进度只计该路线课程，章节完成记录按课代码共享。
- localStorage 的读写均捕获异常。存储不可用时仍保留本页交互，并提示本页临时记录；所有进度文案明确是自评，不是掌握或数学审查认证。
- URL 从模块地址推导站点根，兼容 GitHub Pages 仓库子路径。当前路线的所有课路径都能正确从 `.md` 转成目录 URL。
- 章节页按已选路线提供上一课、下一课；末课进入该路线的 `#project`，目标锚点存在。
- 路线导航有可理解的 `nav` 标签和 `aria-current`。完整 MkDocs 导航仍可由原生按钮展开，`aria-expanded` 与 `aria-controls` 同步；CSS 对 hidden 导航有明确处理。
- 控件采用原生 checkbox、radio、button，配套 label；诊断分组使用 fieldset/legend，反馈采用 `role=status` 和 `aria-live=polite`。未答题不会被判作通过。
- fetch 失败提供回退提示；静态课表、原文及原生 details 提示/答案仍保留。关闭 JavaScript 时完整 MkDocs 导航仍可使用，没有依赖脚本才存在的唯一阅读路径。
- 当前 MkDocs 未启用 `navigation.instant`，模块仅初始化一次与现有普通页面跳转一致；将来若启用即时导航，需要另行适配重新初始化。

以上是源码层面的可访问性检查，不代表已完成键盘、屏幕阅读器或所有浏览器的操作认证。
