# H2 仿射链实验：定义、核验范围与限制

日期：2026-10-15。实现仅依赖 Python 标准库；运行入口：

~~~text
python scripts/subdivision_chains.py
python scripts/test_subdivision_chains.py
~~~

## 数学对象与约定

每个生成元是实仿射空间中的有序仿射奇异单形，其顶点坐标属于有理数。坐标用 Fraction 存储，不表示单形的像位于有理点空间。链系数是整数；不接受浮点数、布尔值或字符串偷偷进入计算。

保持顶点顺序和重复顶点。两条相反参数化的边是不同自由生成元；重复顶点的奇异单形也不是零。程序只合并完全相同的有序元组，并在整数系数真实相消时删除零系数。没有取交替定向商，也没有取退化链的商。

采用增广链：空元组为负一维生成元，零维顶点的边界为该空元组；负一维边界是零。程序的负二维只容纳终端零群，不引入额外生成元。锥算子在前端插入顶点，因此满足增广锥恒等式。

Sd 在负一维和零维为恒等；正维先细分边界，再以该生成元重心作锥。T 在负一维和零维为零；正维对原链减去细分链、再减去边界的 T 像所得残差作锥。符号约定为边界 T 加 T 边界等于 id−Sd。重复细分的链同伦采用 T_N = sum(T Sd^j, j=0,...,N−1)。

## 独立参照与检查范围

| 检查 | 输入与断言 |
|---|---|
| 独立细分参照 | 枚举顶点删除的全部排列，以排列符号加权“全体重心、逐次删点后的面重心、最后顶点”的降序旗标；参照不调用递归边界、锥或 Sd |
| 标准单形 | 维数0至4；Sd 与旗标逐生成元、逐整数系数相等，项数为阶乘 |
| 退化枚举 | 三个二维点上长度1至4的全部120个有序元组，包括重复点、全常值和不同顺序 |
| 链恒等式 | 上述输入核对边界复合为零、Sd 与边界交换、边界 T 加 T 边界等于 id−Sd；没有浮点容差 |
| 低维符号 | T1 显式三项含两个退化锥项；常值边非零、Sd 为真实相消的零、T 为常值三角形；T2 从显式边 T 和独立旗标组成循环残差 |
| 仿射自然性 | 16个维数/映射组合，含零秩、全顶点合并、映入零维实空间及固定种子的有理矩阵；检查边界、Sd、T 及两次细分 |
| 支撑 | 标准单形中的每一顶点检查坐标非负、和为一，构成精确重心坐标证书；覆盖 Sd、T 和选定的重复细分/链同伦 |
| 网格 | 最大范数下使用 Fraction 精确比较；维数1重复5次、维数2重复3次、维数3重复2次、维数4重复1次，核对 n/(n+1) 的逐次界；另含有理共线三角形 |
| 有限链 | 两个分离三角形的整数系数组合，检查线性性、N=0/1/2链同伦、统一N=2后所有项直径小于1/2 |
| 输入边界 | 增广层、零链、真正系数相消、维数不一致、非法系数/坐标/迭代次数 |

全部11个测试的实际输出保存在 subdivision-tests.txt。代码与测试文件的 SHA256 写入同一日志，以便确认该日志所对应的版本。

## 不由这些测试建立的结论

- 测试没有对任意连续奇异单形进行枚举，也没有对一般拓扑空间的链群做形式化验证。一般性来自正文对递归、自然性、支撑、网格界和有限链统一细分的证明。
- 精确网格比较选用最大范数。正文中任意范数下的同一收缩上界需要数学证明，不能从有限实验推广。
- 支撑检查不声称 T 本身收缩网格；T 保留原单形顶点，保证的是像留在原单形中。
- 空间开覆盖、Lebesgue 数与切除定理的假设不是此程序的输入。有限链上统一 N 的数值例不能代替这些论证。
- 高维和反复细分的项数增长很快。实现及缓存用于低维教学，不宣称高效、通用的持续同调或奇异同调计算器。
- 测试通过不是独立人类同行评审或形式化证明完成的声明。
